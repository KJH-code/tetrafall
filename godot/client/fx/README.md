# 이펙트 (fx/) — W18 감사·개선 (2026-11-04)

재혁 방향 (2026-11-04): 게임 자체는 JS 와 거의 같아졌으니 '고도로 더 올리기' 중 하나 = **이펙트 (타격·스킬·폭발)**. PC 주력, 웹 맛보기.

## 1. 감사 (W18 시작 = `e15c493` v0.1.4 기준)

비용: **그리기** = 그 효과가 떠 있는 동안 늘어나는 그리기 호출 (MultiMesh 인스턴스는 0 — 풀이 이미 그려지고 있으면), **물체** = 노드. 파편 = `effects.burst` (상자 MultiMesh), 고리 = `effects.ring` (W18 전엔 고리마다 MeshInstance = 그리기 1).
