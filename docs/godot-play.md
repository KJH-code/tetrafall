# 고도 판 켜기: 재혁 PC (윈도우) 한 장

C# 서버 + 고도 클라를 묶은 zip 하나면 끝이다. 받는 PC 에는 .NET·node·고도 모두 필요 없다.

## 1. 받기

**A. zip 을 받았으면** `tetrafall-win-x64.zip` 을 아무 폴더에 풀면 된다 (예: `D:\tetrafall-win-x64\`).

| 파일 | 하는 일 |
| --- | --- |
| `start-online.bat` | 서버 + 인터넷 터널 → 친구용 https 주소 |
| `start-lan.bat` | 서버만 (같은 Wi-Fi) |
| `tetrafall.exe` | 고도 PC 클라 (이 PC 서버에 바로 붙음) |
| `Tetrafall.Server.exe` | 서버 (bat 이 켬) |
| `web/` | 친구 브라우저용 고도 웹 빌드 (서버가 `/play/` 로 줌) |
| `cloudflared.exe` | 터널 (없으면 아래 설치) |

**B. 직접 만들기** (레포에서, 한 번만 설치: .NET 10 SDK · Node 22 · 고도 4.7.2 + 내보내기 템플릿 — 고도 편집기 `편집기 → 내보내기 템플릿 관리 → 다운로드`)

```
git pull
node godot/server/tools/package.mjs --godot "C:\Godot\Godot_v4.7.2-stable_win64_console.exe" --targets win --cloudflared
```

→ `dist\tetrafall-win-x64.zip` (+ 같은 이름 폴더). 고도 내보내기를 이미 해 뒀으면 `--godot …` 대신 `--no-godot`. 리눅스 묶음은 `--targets linux` (둘 다면 `win,linux`).

## 2. 켜기

1. `start-online.bat` 을 두 번 클릭한다.
2. 처음이면 윈도우 방화벽 창이 뜬다. **개인 네트워크 허용**을 누른다 (같은 Wi-Fi 친구가 붙으려면 필요).
3. 창에 `[터널] … 확인 중…` 이 보이다가 `=====` 상자에 `https://단어-단어-….trycloudflare.com` 이 나오면 준비가 끝난 것이다. 이 주소는 클립보드에도 복사돼 있다.
   - `cloudflared 가 없어…` 가 뜨면 `winget install --id Cloudflare.cloudflared` 를 실행하고 창을 다시 연다. 아니면 `cloudflared.exe` 를 이 폴더에 넣어도 된다.
4. 나는 `tetrafall.exe` 를 켠다. 브라우저로 `http://localhost:3000` 을 열어도 된다.

끄기: 서버 창을 닫거나 `Ctrl+C`. 판 기록은 `logs\` 폴더에 남는다.

## 3. 친구에게 링크

- **인터넷 친구**: 상자의 https 주소를 메신저로 보낸다. 친구는 크롬이나 엣지로 열기만 하면 되고 설치는 없다.
  - 방을 만든 뒤 대기실 **링크 복사** 를 누르면 그 주소 + 방 코드 (`…/?room=ABCD`) 가 복사된다. 친구는 그 방으로 바로 들어온다.
  - 주소는 켤 때마다 바뀐다. 터널이 죽으면 서버가 cloudflared 를 다시 켜서 **새 주소**를 창에 띄운다 (방·판은 그대로). 그때는 새 링크를 다시 보낸다.
- **같은 Wi-Fi 친구**: `start-lan.bat` 창의 `다른 PC에서 (…): http://192.168.x.x:3000` 주소를 보낸다.
- **친구가 PC 클라로**: `tetrafall.exe -- --server wss://단어-단어-….trycloudflare.com` 으로 연다. 같은 Wi-Fi 면 `ws://192.168.x.x:3000`.

## 화면이 작거나 느릴 때 (v0.1.1-godot-preview 부터)

- **UI 가 작다**: 설정 > 'UI 크기' 에서 자동·80~200% 를 고른다. 자동은 창 크기 (기준 1280×720) 와 윈도우 화면 배율에 맞춘다.
- **느리다**: 설정 > '화질' 에서 자동·높음·보통·낮음. 자동은 내장 그래픽이면 낮음, 창이 2560×1440 보다 크면 보통. 느리면 '낮음' 을 직접 눌러 본다.
- **어느 그래픽카드로 도는지**: 타이틀·메뉴 왼쪽 아래에 그래픽카드 이름이 작게 나온다. 내장 그래픽(Intel)으로 돌면 노란 안내가 뜬다. `start-lan.bat`·`start-online.bat` 은 처음 켤 때 `tetrafall.exe` 를 고성능 그래픽으로 등록한다 (노트북은 한 번 다시 켜야 적용).
- **숫자 보내기**: 먼저 아래 '데이터 보내는 법' (결과 화면 [성능 보고 복사] 또는 F4) 을 쓴다. 더 자세한 값이 필요하면 느린 화면에서 **F3** 을 누르면 성능 패널이 뜬다 (FPS·프레임 ms·그리기 수·그래픽카드·화질). **Ctrl+C** 로 한 줄이 복사되니 그대로 붙여 보내 준다 (타이틀·대기실·판 중 각각).

## 데이터 보내는 법 (W48 — 느림·끊김·모션 어색함을 클릭 한 번으로)

F3 한 줄·`hitches.txt`·`motion_qa.txt` 를 따로 찾아 보내던 절차를 없앴다. 지금은 **버튼 하나 → 채팅에 붙여넣기**.

1. **게임 안**: 한 판을 하고 결과 화면 (또는 대기실) 의 **[성능 보고 복사]** 버튼을 누른다. 판 도중에도 **F4** 를 누르면 지금까지의 보고서가 복사된다 (키는 설정 > 기타 '성능·모션 보고서 복사' 에서 바꿈). 아래 가운데에 '복사됨 — 채팅에 붙여 넣어 주세요' 가 뜨면 끝 → 채팅에 **Ctrl+V**.
   - 웹 (브라우저) 이나 복사가 확인되지 않으면 보고서 글 전체가 선택된 글 칸으로 뜬다. 그 안에서 Ctrl+C.
   - 판이 끝날 때 보고서를 미리 만들어 두므로 결과 화면에서 누르면 바로 복사된다 (렌더 비용 없음). 판에서 한 번도 안 뛰었으면 '아직 판 기록 없음' 과 환경 정보만 나온다.
2. **게임을 끈 뒤**: 배포 폴더의 **`보고서-복사.bat`** (윈도우, 더블클릭) / `report.sh` (리눅스) 를 켠다. 저장 폴더의 `last_report.txt` (마지막 판 보고서) + `hitches.txt` 앞 30줄 + `motion_qa.txt` 를 합쳐 클립보드에 넣고 창에도 보여 준다 → 채팅에 Ctrl+V. (`report.bat` 은 한글 이름이 깨지는 압축 풀기 도구용 같은 파일.)
3. 보고서는 **파일로도** 남는다: `user://last_report.txt` = `%APPDATA%\Godot\app_userdata\Tetrafall\last_report.txt` (리눅스 `~/.local/share/godot/app_userdata/Tetrafall/`).

**보고서에 들어가는 것** (한 덩어리, 1500자 이하): 버전 (태그·커밋) · OS · GPU (내장·소프트웨어 표시) · 렌더러 · 창 크기 · UI 배율 · 3D 배율 (현재, 판 중 최저) · 화질 · 캐릭터·인원 (봇)·맵·모드·판 길이 · 평균 FPS·1% low·최악 프레임 ms (언제) · 엔진 처리 ms·렌더 CPU/GPU ms·영상 메모리 · 히치 횟수·최악·**원인 상위 5개** (해상도 변경·몸 만들기·KO·스킬 …)·해상도 변경 횟수 · 모션 팝 (캐릭터별 팝 수/관측 초 + 상위 5개) · 켜진 옵션 (`--old-gait`·`--no-w43` 같은 비기본 인자 이름만).
- F3 를 켜지 않아도 FPS·1% low·히치 원인은 판 중 가볍게 모인다 (프레임당 몇 µs). F3 를 켜 두면 스크립트·렌더 CPU ms 가 더 들어간다.
- **개인정보는 안 들어간다**: `C:\Users\이름\AppData\Roaming` → `%APPDATA%`, `C:\Users\이름` → `%USERPROFILE%`, 리눅스·맥 홈 → `~`, 이 PC 사용자·컴퓨터 이름 → `<사용자>`. 서버 주소·방 코드·닉네임·파일 경로 인자 (`--server`·`--room`·`--name`·`--shot` …) 는 옵션 줄에서 뺀다.
- 모션 팝은 새 모델 몸이 판에 있을 때만 나온다. 몸 하나를 0.5초씩 번갈아 지켜본 표본이라 '팝 수/관측 초' 로 읽는다 (전체 판정은 `--motion-qa` 재연 도구).

## 렌더러 비교 (v0.1.2-godot-preview 부터)

같은 폴더에 렌더러만 다른 시작 파일이 있다: `start-lan-compat.bat` (지금 기본), `start-lan-forward.bat` (Forward+), `start-lan-mobile.bat` (Mobile). 각각 켜서 판 중에 **F3 → Ctrl+C** 로 복사한 한 줄을 하나씩 보내 주면 PC 기본 렌더러를 숫자로 정한다. 타이틀 왼쪽 아래 글자에 지금 렌더러가 나온다.

`start-lan-ext.bat` = 새 Blender 탱크 시험: 서버와 PC 클라를 `--ext` 로 같이 켬. 탱크를 고르면 새 모델 (기본 start-lan 은 그대로).

### 어느 시작 파일을 쓸까 (렌더러 고르기, W36)

| 파일 | 렌더러 (드라이버) | 언제 |
| --- | --- | --- |
| `start-lan.bat` · `start-online.bat` | GL Compatibility (opengl3) — **기본, 웹과 같은 빌드** | 평소에 하는 판. 아무 PC 에서나 돎 |
| `start-lan-compat.bat` | 같은 GL Compatibility | 아래 비교의 **기준**. 서버와 클라를 한 번에 켜는 것만 다름 |
| `start-lan-forward.bat` | Forward+ (Vulkan) | 새 그래픽카드 (RTX 등) 에서 그림자·반사가 더 부드러운지 보고 싶을 때 |
| `start-lan-mobile.bat` | Mobile (Vulkan) | Forward+ 보다 가볍다는 쪽. 같은 판에서 FPS 가 더 나오는지 볼 때 |

**기본은 안 바꾼다.** 렌더러마다 그림이 조금 다를 수 있고 (색·그림자), 소프트웨어 렌더 측정으로는 GPU 시간을 못 재서, 재혁 PC 의 숫자가 나온 뒤에 정한다. 컨테이너에서 잰 비교표 (그리기·삼각형·영상 메모리·첫 그리기 시간) 는 [`godot/README.md` 렌더러 시험](../godot/README.md#렌더러-시험-w12-2026-11-03--결정은-재혁-pc-숫자-뒤).

**측정 부탁 (세 번, 10분이면 끝)** — 세 시작 파일을 각각 켜서 같은 조건으로:

1. 방을 만들고 봇 7명을 넣어 **8명 판** 한 판 (맵은 매번 같게, 창 크기도 같게).
2. 판이 한창일 때 **F3** 을 켜고 **Ctrl+C** — 한 줄이 복사된다. **첫 줄에 `렌더러 …` 와 그래픽카드 이름**이 들어 있으니 어느 시작 파일의 숫자인지 그대로 보인다.
3. 세 줄을 (compat · forward · mobile 순서로) 붙여 보내 준다. 랙이 있었다면 `%APPDATA%\Godot\app_userdata\Tetrafall\hitches.txt` 도.

보는 줄: `FPS`·`1% low` (낮은 쪽이 끊김), `렌더러`·`GPU`, `그리기`·`삼각형`, `영상 메모리`, 첫 순간 끊김 (`히치`). 렌더러가 Vulkan 인데 GPU 이름이 `Intel …` 이면 내장 그래픽으로 돈 것이니 위 '어느 그래픽카드로 도는지' 를 먼저 고친다.

## 웹판 (친구 브라우저) — 첫 화면과 주소 인자 (W36)

- **첫 화면 시간**: 웹 묶음은 wasm (공식 템플릿 39.5MB, 압축 전송 6.9MB) + `index.pck` (10.5MB, 압축 7.5MB) 를 받고 wasm 을 컴파일한 뒤에야 타이틀이 뜬다. 10Mbps 흉내로 **약 16.6초** (받는 양 약 14.5MB). 로딩 화면은 받는 동안 %, 다 받으면 `LOADING` 막대, 오래 걸리면 안내 문구 (6초 넘게 받는 중이면 '처음 한 번만 오래 걸려요', 켜는 중이 4초 넘으면 '5~15초 더') 를 보여 준다. 서버가 파일을 `no-cache` (재확인) 로 줘서 두 번째부터는 변하지 않은 파일을 다시 안 받는다.
- **작은 웹 템플릿** (직접 빌드, wasm 32.9MB·압축 5.4MB): 같은 조건 첫 화면 **약 15.0초** (−1.6초), 받는 양 14.5 → 13.0MB. 릴리스에는 기본 **꺼져** 있다 — 켜는 법은 [`godot/server/README.md`](../godot/server/README.md) (저장소 변수 `WEB_TEMPLATE_BUILD=true`).
- **첫 대기실·첫 판 멈춤**: 소프트웨어 렌더 (llvmpipe) 기준 켜는 동안 한 번 약 4~5초 (wasm 컴파일·엔진 켜기), 첫 대기실 입장 때 약 0.7초, 첫 판 시작 때 약 0.7초 프레임이 멈춘다 (셰이더 컴파일). 진짜 GPU 에서는 훨씬 짧을 것이다. 재는 법: `godot/client/tools/web_first.cjs` (첫 화면)·`web_lobby.cjs` (대기실·판 멈춤).
- **주소 인자** (`https://…/play/?키=값&키=값`): 데스크톱의 `-- --키 값` 과 같은 인자가 웹에서도 먹는다.

| 인자 | 하는 일 |
| --- | --- |
| `room=ABCD` | 그 방으로 바로 들어옴 (대기실 '링크 복사' 가 이것) |
| `server=wss://…` | 붙을 서버 (기본은 이 페이지를 준 서버) |
| `gfx=low` · `medium` · `high` | 화질을 이번만 고정 (웹 기본은 `low`: 그림자·블룸·거울·외곽선 끔, 3D 해상도 0.75). 설정 창에서도 바꿀 수 있음 |
| `perf=1` | F3 성능 표시를 켠 채로 시작 (`hitch=1` 은 패널 없이 랙 기록만) |
| `no-bake=1` | 구운 몸 텍스처를 안 씀 (확인용) |
| `no-ext=1` | 새 Blender 모델 끔 — 웹은 이미 기본이 끔이고 웹 묶음에는 그 모델 파일이 없음 |
| `title=테마id` | 타이틀 테마 고정 (확인용) |

주의: 적응형 3D 해상도는 웹·소프트웨어 렌더에서는 돌지 않는다 (`adapt=1` 로 강제하면 돎, 확인용).

타격 4단계 (약·중·강·치명) 마다 번쩍임·충격파 링·밀치는 방향 불꽃·먼지, 강타·치명타에 아주 짧은 화면 멈춤 (히트스톱)·카메라 튐, 1인칭 팔 반동, 8명 스킬 이펙트 (탱크 땅 가르기 먼지·돌 조각, 사냥꾼 표식 폭발, 광전사 분노 김, 닌자 손 불티, 바드 속도선 등), 폭탄·대포·건축가 폭파의 화염구·충격파·연기·파편, 낙사 잔상·압사 먼지. 세기는 `godot/client/fx/fx_config.gd` 한 곳. 설정의 '움직임 줄이기' 를 켜면 흔들림 약하게·히트스톱 끔, 화질 '낮음' 이면 새 효과 꺼짐 (JS 수준).

## v0.1.10 에서 바뀐 것 (초상·대기실·1인칭 팔 다듬기)

- **화면 아래 사람 카드·대기실 카드 초상**: 모델마다 키·머리 위치에 맞춰 얼굴이 잘리지 않게 (새 모델 4명 + 예전 몸 4명). 새 모델의 팀 색 칸도 초상에 플레이어 색으로 나옴.

여전히 T 포즈가 보이면 그 순간 스크린샷을 보내 주세요 (소프트웨어 렌더로만 확인해서 PC 체감은 못 봄).

## v0.1.11 에서 바뀐 것 (최적화: 새 모델 순간 끊김·웹 경량화)

- **새 모델 순간 끊김 원인을 찾아 고침**: 새 캐릭터가 처음 나올 때마다 모델 파일·텍스처를 메인 스레드에서 읽는 데 114~163ms, 처음 그릴 때 첫 프레임 133~363ms 가 걸렸음. 모델 텍스처를 압축 (읽기 100~120ms → 2.4ms, 캐릭터당 영상 메모리 21MB → 약 5.6MB), 메뉴에서 쉴 때 모든 모델을 미리 읽고 캐릭터마다 몸을 아주 작게 미리 그려 둠 (첫 프레임 9~21ms). 끄려면 클라를 `-- --no-ext-warm` 로.
- **히치 로거 (랙 원인 찾기)**: F3 를 켜면 프레임이 평소 중앙값의 2배 (최소 20ms) 를 넘는 순간을 `%APPDATA%\Godot\app_userdata\Tetrafall\hitches.txt` 에 시각·화면·원인 추정과 함께 적음. F3 패널 맨 아래와 '복사' 한 줄 끝에 `히치 N회 · 최악 xxms · 원인 상위: …` 가 붙으니 한 판 뒤 그 한 줄을 보내 주세요. 패널 없이 기록만 하려면 `-- --hitch`.
- **웹판 경량화**: 웹은 기본이 예전 몸 + 화질 낮음 (MSAA·그림자·블룸·거울·외곽선 끔, 3D 해상도 0.75, 먼 몸 포즈 간격↑), 웹 묶음에서 새 모델 파일을 빼 `index.pck` 36.8MB → 10.5MB. 웹 주소에 `?no-ext=1`·`?gfx=…` 같은 인자가 이제 먹음 (웹은 명령줄이 없어 예전엔 안 먹었음). 설정 창에서 화질을 올릴 수 있음. 소프트웨어 렌더 측정에서 8명 판 프레임 235 → 73ms (720p). PC 는 그대로.
- 랙이 남아 있으면: 노트북이면 Windows 설정 > 그래픽에서 이 게임을 '고성능 (RTX)' 으로 지정했는지, F3 의 GPU 이름이 RTX 인지 확인.

## v0.1.12 에서 바뀐 것 (최적화 2차: 적응형 해상도·가벼운 판 몸·외곽선 거리)

- **3D 해상도 자동 (적응형)**: 판 중에 GPU 가 병목일 때만 3D 렌더 배율을 0.6~1.0 사이에서 서서히 조절 (내릴 땐 빠르게, 올릴 땐 약 2초 여유가 있을 때 조금씩, 올렸다 곧 도로 내리면 한동안 다시 안 올림). 바닥 배율에서도 느리면 MSAA 를 한 단계 낮췄다가 판이 끝나면 되돌림. 대기실·메뉴·결과는 고정, 2D UI 는 원본 해상도. 설정 창 '시점' 줄 '3D 해상도 자동' 체크 (새 설치 기본 켬, 예전에 화질을 직접 골라 둔 설정은 꺼짐), F3 에 `3D N%` 와 '자동 해상도 (천장 N%)', 히치 로거에 `해상도 변경` 태그. 웹·소프트웨어 렌더에서는 안 돎. 끄려면 설정에서 체크 해제.
- **판용 몸 삼각형 감소** (닌자·탱크·갈고리): 새 UV 로 다시 펼쳐 알베도를 다시 굽고 (1024) 판 LOD 를 몸 하나 약 8.5~9천 → 5천 (높음) / 4천 (보통) / 3천 (낮음) 삼각형. 같은 캐릭터 8명 판 삼각형 약 14만 → 8만 / 6.4만 / 4.8만. 팀 색 칸 경계가 삼각형 하나만큼 어긋나 연회색/어두운 팀 색으로 조금 보일 수 있음, 낮음 단계에서 탱크의 가는 장식 선이 조금 뭉개짐.
- **먼 몸 외곽선**: 카메라에서 8m 부터 가늘어지고 16m 에서 0.25배, 그 너머는 외곽선을 뗌 (전체 보기에서 삼각형 −29%, 3인칭에서는 −3.5%). 끄려면 클라를 `-- --no-outline-far` 로.
- 확인 부탁: 랙이 남아 있으면 F3 를 켜고 한 판 뒤 복사 한 줄 (GPU 이름·FPS·1% low·`3D N%`·히치 요약) 을 보내 주세요.

## v0.1.13 에서 바뀐 것 (그림자 최적화·새 동작 클립·하이브리드 GPU 경고)

- **몸 압박 단계 (W45)**: 적응형 3D 해상도가 바닥 (0.6) 이고 MSAA 도 낮춘 뒤에도 GPU 가 느릴 때만 먼 몸 외곽선 앞당김·자세 LOD (1단계), 먼 몸 그림자 거리 줄임 (2단계). 판이 끝나면 복귀. `--no-body-pressure`.
- **영상 메모리**: 대기실 큰 캐릭터 렌더 대상이 판 중에도 남던 것을 2×2 로 줄임 (−7MB, UI 배율 2 에서 약 −28MB). `--no-stage-shrink`.
- **로그 경고 폭주 가드**: 맞음 움찔·천 회전 계산에서 부모 뼈 변환이 NaN/영 스케일일 때 엔진 경고가 초당 수천 번 찍히던 것을 막음 (20초 재연 경고 20건 → 0). NaN 이 처음 생기는 원인은 아직 모름.
- 알려진 것: 입장 첫 바퀴 최악 프레임이 아직 25ms 를 조금 넘음 (바탕 비용), 닌자 대시 팔 74~129° 튐·래그돌 복귀 팝 (보류), 탱크 허리 앞 천·어깨 장갑 2차 모션 (모델에 지오메트리 없음), 어깨 박치기·돌진·스핀·주먹 공격/회복 구간 다리 팝 37건 (서버 `moves` 설계값). 비교용 기준선 프레임 구성표는 `docs/w45/README.md`.

## 안 될 때

| 증상 | 할 일 |
| --- | --- |
| 친구 화면에 Cloudflare 530·1033 | 상자가 뜨기 전에 연 것. 상자가 뜬 뒤 다시 연다 |
| 터널을 6번 켰는데 안 열림 | 잠시 뒤 `start-online.bat` 다시. 서버는 켜져 있어 같은 Wi-Fi 는 된다 |
| 3000 포트를 이미 씀 | 다른 서버(`npm start` 등)를 끄거나, 창에서 `set PORT=3100` 한 뒤 `Tetrafall.Server.exe --online` |
| 같은 Wi-Fi 친구가 못 붙음 | 방화벽에서 `Tetrafall.Server` 를 개인 네트워크 허용 |

자세한 터널 방식 (주소 확인·다시 켜기·고정 주소) 은 [online.md](online.md). 서버 옵션: `--online` (= 환경 변수 `TF_ONLINE=1`), `PORT`, `CLOUDFLARED` (cloudflared 경로).
