# 캐릭터 설계

C 설계 세션 산출물. 구현은 A(서버)·B(화면)가 한다. 수치는 전부 초안이고 실제 값은 봇 판·사람 테스트로 맞춘다.

## 0. 설계 틀

새 캐릭터는 이 틀부터 채운다. 남의 **기술**은 가져오지 않고 **원리**만 쓴다.

### 0.1 지킬 방향 (재혁)

| 항목 | 내용 |
|---|---|
| 톤 | 속은 격투, 겉은 병맛 (TABS). 판정은 AABB 그대로, 몸만 흐물 |
| 콤보 | 운이 아니라 실력. 캐릭터마다 고유 콤보·장단점 |
| 평타 | 지상·공중이 다름 |
| 금지 | 운빨, 억까. **콤보 마무리로 상대를 블록 밑에 보내 압사시키는 연계** |
| 정체성 | 블록·지형이 바뀌는 필드에서 싸움 |
| 탱크 | 버서커 아님. 반격형 (돈키호테 원리) |
| 로스터 | 초보 추천캐(연타 + 생존기) 최소 1명 |

### 0.2 축

| # | 축 | 값 |
|---|---|---|
| 1 | 콤보 형태 | 긴 연계 / 짧은 폭딜 / 견제 |
| 2 | 시작기 | 지상 평타 / 공중 스킬 / 원거리 적중 후 접근 / 돌진 / 설치물 |
| 3 | 적중 보상 | 스택·표식 / 쿨 감소·초기화 / 이속 / 없음 |
| 4 | 필살기 자원 | 게이지 / 스택 / 쓴 만큼 셈 / 강화 모드 / 특정 행동으로만 충전 |
| 5 | 이동·생존 | 적중형 순간이동 / 설치형 순간이동 / 돌진 / 은신 / 없음 |
| 6 | 빗나갈 때 벌 | 큼 / 작음 |
| 7 | 숙련 | 바닥(시작 난이도) · 천장(잘하면 얼마나 셈) |
| 8 | 약점 방향 | 원거리에 약함 / 붙으면 약함 / 쿨 빠지면 약함 |
| 9 | **지형 활용** (우리 고유) | 블록을 만듦 / 블록을 씀 / 무관 |
| 10 | 남에게 주는 영향 | 없음 / 표식(모두의 표적) / 장판(누구나) / 폭탄화 |
| 11 | 아머·방어 | 없음 / 슈퍼아머(깨지는 조건) / 패리 / 피해 감소 |

규칙: 4명이 **2·3·4번 축에서 같은 값을 쓰지 않는다.** (지금은 4명 다 지상 평타 시작 · 적중 보상 없음 · 게이지라서 캐릭터 차이가 수치뿐)

### 0.3 유형

| 유형 | 축 조합 | 참고 (스매시 레전드) |
|---|---|---|
| 돌파형 | 짧은 폭딜 + 돌진 + 빗나가면 벌 큼 | 스노우, 레드, 피터 |
| 연계형 | 긴 연계 + 공중 시작 + 숙련 천장 ↑ | 쿠레나이, 우치, 신디 |
| 사냥꾼형 | 스택 쌓기 → 터뜨림 | 구미, 마스터 캣, 하멜린 |
| 지형·설치형 | 설치물로 공격·이동·엄폐 | 브릭, 아오이, 빅터 |
| 디버프·제어형 | 상대 행동을 제한 | 파르페, 앨리스, 라푼젤 |
| 버티기(반격)형 | 맞을수록 이득, 방어 중 반격 | 돈키호테, 카이저 |
| 추적형 | 원거리 적중 → 접근 | 자베르, 알리, 오공 |
| 견제형 | 원거리로 공간 잡기 | 로빈, 후크 |
| 서포터형 | 아군 지원 | 골디, 옥타비아 |
| 카운터형 | 상대 공격에 맞춰 받아침 | 몰리, 스피로 |

### 0.4 서포터·디버프 원칙

팀전은 있지만(`server/game.js` `teamMode`) 기본은 개인전이고 얼마나 할지 모른다.

| 원칙 | 이유 |
|---|---|
| 순수 서포터(회복·아군 버프만) 금지 | 개인전에서 쓸모없음. 피해 %는 넉백 배율이라 회복도 약함 |
| 지원 효과는 **팀전이면 아군, 개인전이면 나 또는 누구나** | 예: 장판·길은 들어온 누구나, 표식은 때린 누구나 이득 (골디 원리) |
| 디버프는 "상대가 **블록·지형을 다루기 어렵게**" 쪽 | 둔화, 점프 감소, 넉백 더 받음. 정체성과 맞음 |
| 시야 방해 금지 | 블록 그림자를 가리면 압사 억까 |
| 기절은 0.5초 이하 + 맞기 전 예고 | 억까 방지 |

### 0.5 공통 시스템 후보 (캐릭터와 별개, 재혁 결정 필요)

| 후보 | 상태 | 메모 |
|---|---|---|
| DI (맞을 때 방향키로 넉백 방향을 조금 틂) | 재혁 찬성 | 입력은 이미 서버로 감. 예측 없어도 됨 |
| 필살기 시전 순간 슈퍼아머 (전원) | 제안 | "스킬 씹힘"이 R에서는 사라짐. 강한 공격에 깨지는 조건 (티문 원리) |
| 공중 스킬을 지상 스킬과 다르게 | 재혁 찬성 | 쿠레나이 바람의 술처럼 |
| 콤보 끝 무적 0.3초 | 유지 제안 | 낙사 71%라 스레처럼 끝까지 맞으면 콤보 하나 = 죽음 |
| 스펠 (판 전에 고르는 공용 부가 효과: 고정딜, 도약, 1초 무적, 필살기 재충전 등) | 보류 | 스레 시스템. 캐릭터 정하고 나서 |

### 0.6 재혁 취향 (편향 확인용)

| 좋아함 | 이유 | 축으로 |
|---|---|---|
| 빅터 | 지뢰 깔고 한 번에 펑, 뇌지컬, 재능 연계로 천장 높음. **공격적으로** 씀: 스킬·스킬·궁, 공중 평타·스킬·평타. 공격 오면 공중 스킬로 피하고 남은 지뢰로 반격 | 설치형인데 설치물이 **콤보 부품 + 반격 자원**. 니가와 아님 |
| 후크 | 궁 뒤에 스킬 + 각성 + 스펠 + 재능이 겹쳐 딜이 미침 | 강화 창 + 자원 겹치기 |
| 구미 | 표식 있는 상대를 궁으로 맞히면 궁이 다시 참 → 콤보 아니어도 평·궁 연발로 다 쓸어버림 | 사냥꾼형 + 조건부 필살기 재충전 |
| 나르샤 | 위에서 나만의 게임 | **우리 게임에는 안 넣음** (재혁) |

| 싫어함 | 이유 | 피할 것 |
|---|---|---|
| 티르핑 | 사기, 밸붕 | 대가 없는 장점 |
| 니가와 캐릭터 | 재미없고 비매너 | 설치물·방어가 대기 플레이가 되는 구조 |
| (예전 생각의) 탱크 | 손맛 없음 | 탱크는 반격형으로 |

편향 경고: 좋아하는 셋 다 숙련 바닥·천장이 높다. 초보 추천캐는 따로 의도해서 만든다.

## 3. 캐릭터

### 3.1 건축가 (확정 2026-10-25, 수치는 초안 · 밸런스는 나머지 캐릭 만든 뒤 A 가 봇 판·사람 테스트로)

| 항목 | 내용 |
|---|---|
| 유형 | 지형·설치형. 어려운 캐릭 (뇌지컬, 천장 높음) |
| 한 줄 | 깔고, 쳐서 터뜨린다 |
| 장점 | 설치물이 공격·연계·복귀를 다 함. 깔아 둔 블록이 R 대폭발과 같이 터짐 |
| 단점 | 깔기 전엔 약함. F 를 복귀에 쓰면 공격 수단이 줄어듦. 준비·후딜이 느림 |
| 무기 | 망치 (아이템 망치 텍스처 재사용) |
| 고유 축 | 시작기 = 설치물 · 적중 보상 = 블록 폭발로 R 게이지 · 지형 = 블록을 만들고 부숨 |

#### 건축가 블록 (공통)

| 규칙 | 값 (초안) |
|---|---|
| 종류 | 벽 블록 (F) · 3타 블록 (평타) · 발판 (공중 F) |
| 수명 | 8초 뒤 사라짐 |
| 망치로 치면 | **폭발**. 치는 방향 앞으로만 넉백 (건축가 자신은 안 날아감). 벽·3타 블록·**발판 모두** (재혁: 발판도 터지게. 밟고 있는 발판을 치면 떨어짐 = 내 선택) |
| 폭발 피해 (A 구현) | 한 사람당 한 번, "그 사람 가까이 터진 칸 수 × 8" (벽 3칸에 붙어 있으면 24). 넉백 6 · 위 4 · 경직 0.8초 |
| 연쇄 | **같은 F 로 만든 벽 칸끼리만** 번짐. 다른 F 벽·3타 블록으로는 안 번짐 (맵 전체 펑 방지) |
| 누가 터뜨림 | 건축가만 (상대는 못 터뜨림. 1층이라 점프로 넘음 → 니가와 걱정은 사람 테스트로 확인) |
| 3타 블록 개수 | 동시에 최대 3개. 넘으면 제일 오래된 것부터 사라짐 |

#### R 필살기: 대폭발

| 항목 | 내용 |
|---|---|
| 위치 | 내 앞 3×3 (내 칸 앞 한 칸 비우고 2~4칸째) |
| 동작 | 블록 3×3 이 **바닥에서 솟음** (위 사람 띄우기만, 경직 0 — 경직을 주면 콤보 끝 무적 0.3초가 폭발과 겹침) → 0.8초 뒤 자동 대폭발 |
| 대폭발 수치 (A 구현) | 피해 25 · 넉백 7 · 위 6 · 경직 0.9초. 범위는 칸 가장자리에서 1칸 |
| 일찍 터뜨리기 | 망치로 치면 바로 터짐 (고수는 빨리, 초보는 기다림) |
| 보너스 | 폭발 범위 안 내 블록(벽·3타 블록)도 같이 터짐 |

| 기본 (초보) | 평평평(올려치기) → 점프 → 공중 평(내려치기) |
| 뚫기 | 상대가 공격할 때 F 방패 돌진으로 뚫고 → 평평평 → 공평 |
| 역관광 | 실컷 맞아 R 참 → R 내려찍기(아머로 들어감) → 솟는 땅이 띄움 → 공평 |

#### 대응법 · 생존

| | 내용 |
|---|---|
| 상대 대응 | **마무리 타·R 로 아머를 깸.** 멀리서 때리기, 위에서 때리기. F 를 쓴 뒤(쿨 8초)엔 느린 근접 캐릭. 탱크를 많이 때리면 R 이 차니 아무 때나 때리지 않기 |
| 생존·이동 | 덜 밀림, F 돌진, R 아머 |

#### 지금 코드에서 바꿀 점 (A)

| 대상 | 변경 |
|---|---|
| `BASIC_ATTACKS.tank` | 3타 방패 밀기(finish) → 방패 올려치기 (finish 아님, 띄움). 공중 방패 내려치기에 `finish` |
| 아머 (새로) | F 돌진 중·R 떠오르는 동안: 넉백·경직 무시, 피해 % 는 받음. 마무리 타·R 에 맞으면 깨짐. 카운터 예외 |
| `tankCharge` | 지금은 "처음 부딪힌 상대를 치고 멈춤" → 맞아도 안 멈춤 (부딪힌 상대에서 멈추는 건 그대로) |
| `TANK_SLAM_*` | 바깥 고리 블록 1층 솟기 (위 사람 띄움) → 1초 뒤 가라앉음 |
| 패시브 | 받은 피해로 얻는 R 게이지 ×2 |
| 주의 | 예전 봇 판에서 "탱크 킬 대부분 내려찍기" (`TANK_SLAM_DAMAGE` 주석). 게이지 2배로 R 이 더 잦아짐 → 봇 판으로 R 피해·게이지 배율 맞추기 |
| 봇 | 상대가 공격할 때 F 로 뚫기, 맞은 뒤 R (`server/bot.js`) |

#### 화면 (B)

| 대상 | 필요 |
|---|---|
| 아머 | 아머 중 몸이 금속처럼 번쩍 + 맞아도 안 휘청 (TABS: 맞을 때 얼굴만 찡그림) |
| 아머 깨짐 | 유리 깨지듯 파편 + 크게 휘청 |
| F | 방패 앞세우고 돌진 |
| R | 쾅 + 고리 모양으로 땅이 솟았다 꺼짐 |
| 패시브 | 맞을 때 R 게이지가 크게 차는 게 보이게 (게이지 반짝) |

### 3.4 갈고리 (확정 2026-10-25, 수치는 초안 · 밸런스는 A 가 봇 판·사람 테스트로)

| 항목 | 내용 |
|---|---|
| 유형 | 그래플러·컨트롤러 |
| 한 줄 | GET OVER HERE → 탕 |
| 이기는 장면 | 도망치는 상대를 끌고 와서 한 방 |
| 무기·모양 | 갈고리 + 플린트록 (해적) |
| 장점 | 끌어오기로 콤보 시작. 블록에 걸어 이동·복귀. 블록을 뽑아 옮겨 지형을 바꿈 |
| 단점 | F 빗나가면 쿨 8초 = 큰 벌. 블록 없는 평지에선 이동기 약함. 빈 총이면 마무리가 약함 |
| 고유 축 | 시작기 = 원거리 끌어오기 · 적중 보상 = **끌어오면 재장전** · 지형 = 블록에 걸어 날아감, 블록을 뽑아 옮김 |

#### 장전 (플린트록)

| 규칙 | 내용 |
|---|---|
| 한 발 | 장전되어 있으면 평타 마지막 타가 **탕**. 쏘면 빈 총 |
| 재장전 | **F 갈고리로 상대를 끌어오면** 장전 (시간으로는 안 참) |
| 시작 | 판 시작·부활 때 장전된 상태 |
| 의미 | "끌어와야 쏠 수 있다" → GET OVER HERE 와 탕이 한 세트 |

#### 평타

| 타 | 이름 | 동작 | 초안 수치 |
|---|---|---|---|
| 1 | 갈고리 휘두르기 | 지금 1타 | windup 150 · rec 300 · dmg 6 |
| 2 | 주먹 | 지금 2타 (마무리 → 중간 타로) | windup 150 · rec 300 · dmg 6 |
| 3 (마무리, 장전) | **탕** | 플린트록 근접 사격. 샷건·피스톨 느낌. 사거리 2칸, 넓은 각, 넉백 큼 → 빈 총 | windup 200 · rec 500 · dmg 12 |
| 3 (마무리, 빈 총) | 갈고리 내려치기 | 약한 마무리 | windup 200 · rec 450 · dmg 6 |
| 공중 | 갈고리 스핀 | 갈고리를 채찍처럼 **수평으로 한 바퀴** (주변 전부) | windup 150 · rec 400 · dmg 6 |

#### F 스킬: 갈고리

| 경우 | 동작 |
|---|---|
| 상대에 걸림 | 끌어와 내 앞 1칸에 놓음 + **장전** + 이어 치기 창 열림 → 평 · 평 · 탕 |
| 블록에 걸림 | **내가 블록 쪽으로 끌려감** (이동·복귀) |
| 둘 다 있음 | 보는 방향으로 **먼저 닿는 것** (조준이 실력) |
| 빗나감 | 쿨만 돎 |
| 공중 | 됨 → 떨어질 때 블록에 걸어 복귀 |
| 수치 | 사거리 5칸 · 쿨 8초 (지금 값) |
| 판정 | 즉시 (애니만 날아감) |

#### R 필살기: 블록 내려찍기

| 단계 | 동작 |
|---|---|
| 걸기 | 보는 방향 5칸 안 **첫 블록**에 갈고리 (F 블록 걸기와 같은 판정). 없으면 R 안 쓰임, 게이지 그대로 |
| 뽑기 | 블록 1칸이 지형에서 빠져나와 끌려옴 (약 0.3초). **바닥은 못 뽑음** — 쌓인 블록·떨어지는 블록만 (바닥은 격자 칸이 아님) |
| 쾅 | 사슬 끝 블록을 머리 위로 돌려 **앞으로 수직 내려찍기**. 앞 직선 약 5칸, 맞으면 넉백 + 띄움 |
| 박힘 | 블록이 찍은 자리에 **박혀 지형으로 남음**. 그 칸에 사람이 있으면 **압사 대신 밀쳐냄** |
| 필드 밖 | 찍은 자리가 필드 밖이면 블록은 떨어져 사라짐 |
| 크기 | 1칸 (캐릭터 키가 2칸이라 4칸 테트리미노는 너무 큼) |
| 건축가 블록 | 뽑을 수 있음. 옮겨도 **건축가 블록 그대로** (8초 수명, 건축가가 치면 터짐). 건축가 블록은 눈으로 구별되게 (B) |
| 정체성 | **블록이 쌓일수록 강해지는 캐릭터** (F 블록 걸기도 같음). 블록 적은 판 초반엔 약함 = 약점 |
| 지금 회오리 | 버림 (주변 범위는 공중 스핀이 맡음) |

#### 패시브

없음 (평타 사거리 ×1.2 삭제, 재혁).

#### 대표 콤보

| 루트 | 흐름 |
|---|---|
| 기본 | F(끌어옴, 장전) → 평 → 평 → 탕 |
| 빈 총 | 평 → 평 → 내려치기 (약함) → F 로 다시 끌어와 장전 |
| 이동 | F 블록 → 날아가서 공중 스핀 |
| 복귀 | 떨어지며 F 블록 |
| R | 도망가는 상대 → 근처 블록 뽑아 쾅 → 박힌 블록이 길을 막음 → F 로 끌어와 평평탕 |

| 생존·이동 | F 블록 걸기 |
