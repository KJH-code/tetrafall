재혁 F3 숫자는 아직 없음 → 소프트웨어 렌더 (llvmpipe) 에서 믿을 수 있는 값만: 삼각형·그리기·영상 메모리·CPU ms (렌더 끈 재연). 전/후 = 시작 커밋 14ea5fa (worktree) vs 이 브랜치, 같은 녹화·같은 인자 (1280×720, 높음, `frame_budget.cjs`). 녹화는 `tools/rec_chars.mjs` 로 바꾼 것 (new8 = 닌자·탱크·사냥꾼·갈고리 ×2, old8, mixed8, lava8) + 판 후반용으로 새로 녹화한 JS 서버 8봇 99초 판 (`late8`, 쌓인 모양 칸 250, 재생 85초째).

## 2. 새 모델 알베도 지연 로드 (회귀 아닌 진짜 절감)
원인: 모델 .glb 의 장면 (PackedScene) 이 stage 2048² + 판 LOD 1024² ×3 알베도를 전부 쥐고 있었고, `request_all` 의 스레드 하위 읽기 작업도 결과를 붙잡아 안 쓰는 LOD 가 상주.
고침 (`chars/external.gd`): `model_info` 가 장면 재질에서 알베도를 벗기고 경로만 적음 (`tex_path`), 몸을 만들 때 `Ext.tex_of(sf)` 가 그 LOD 것만 `load` (같은 캐릭터 몸은 리소스 캐시로 한 텍스처 공유, 몸이 없어지면 풀림). 미리 읽기는 `use_sub_threads=false`. 끄기 `--no-lazy-tex`. 마스크·얼굴 텍스처는 원래 몸 만들 때 읽음. 측정 `tools/tex_meas.gd` (`--warm` 포함, 영상 MB):

| 장면 | 전 | 후 |
| --- | --: | --: |
| 메뉴 (미리 읽기·데우기 뒤, 몸 없음) | 47.6 | **30.9** |
| 대기실 (닌자 큰 몸) | 48.2 | **34.2** |
| 판 몸 4명 | 54.0 | **42.0** |
| 판 몸 8명 | 55.1 | **43.1** |

몸 만들기 ms 는 같음 (닌자 9 / 탱크 7 / 사냥꾼 8 / 갈고리 8 → 둘째부터 2). 모습: `lod_shot.gd` 24장 화소 차 (>8) 합 2378 (대부분 시간 어긋남), 대기실 stage 캡처는 같은 코드 두 번 돌린 잡음이 더 큼. 재연 (new8): 3인칭 151.2→141.9, 1인칭 174.3→165.0 (이후 칸·지형 변경 포함 161.0).

## 3. 블록 칸 LOD (`world/cell_lod.gd`, 끄기 `--no-cell-lod`, 거리 `--cell-lod-far <m>`)
테마 칸 168~648 삼각형 → 시야각 70° 환산 14m 넘는 칸·조각 (떨어지는 조각은 첫 칸 기준 조각 통째, 하늘 블록은 반투명용 MultiMesh 따로, 쌓인 칸은 카메라가 1m 움직일 때만 다시 가름) 은 낮은 모양 (108 삼각형 둥근 상자 = 화질 낮음이 쓰는 것). 수정 테마 (56) 와 화질 낮음은 안 함. 내가 조종하는 조각은 늘 칸 모양. 그림자 상자는 전부 그대로.

## 4. 지형·먼 배경 (`world/scenery.gd`, 끄기 `--no-scenery-opt`)
`--budget-split` (새 도구) 로 지형·배경 15.9k 를 하나씩 나눠 보니: 하늘 구 1.1k, 지형 칸 5.9k (+그림자 1.8k), 필드 아래 섬 0.8k, 섬 뿌리 바위·먼 섬 3.4k (그림자 3.4k), 구름·먼 산 ~2.5k. 보이는 삼각형은 줄일 만한 큰 덩이가 없고 (장식 `BlockDecor` 는 필드 안이라 거리 LOD·VisibilityRange 이득 없음, 먼 산은 한 메시라 방위별로 쪼개도 <0.7k), **섬·바위·먼 섬이 해 그림자를 던지던 것이 낭비** (그림자가 떨어질 곳이 빛 안 받는 구름 바다뿐) → 그림자 끔: 그림자 패스 지형 6.0k → 1.8k (8명 3인칭 합계 33.8k → 29.5k, 용암 판 13.1k → 9.4k, 그리기 −2). 모습: 재연 화소 차는 같은 코드 두 번 돌린 잡음 (8340) 보다 작음 (6110).

## 5. 몸 자세 CPU (`chars/external.gd` `_code_maps`·`_code_bones`)
렌더 끈 재연 구간 나눔 (`몸 외부 몸 ·…`): 외부 몸 sync 중 뼈 맞추기가 대부분이었음 (몸 하나 0.062ms). 고침: ① 관절 위 부모가 매핑 관절이면 그 자세를 이어 곱함 (뿌리까지 거슬러 올라가지 않게) ② 뼈 쓰기는 매핑된 뼈와 그 조상만 (손가락 끝 뼈 제외). 출력 동일 — 테스트가 예전 알고리즘을 그대로 돌려 네 모델·여러 자세에서 뼈 자세 차 < 1e-4 확인. `tools/pose_cpu.gd` (헤드리스, 몸 하나당):

| | 전 | 후 |
| --- | --: | --: |
| ext.sync (관절→뼈 + 뼈 쓰기) | 0.064ms | **0.023ms** |
| pose() 합계 | 0.20ms | 0.16ms |

렌더 끈 재연 (new8, 8초, 3인칭, 2회): 외부 몸 sync 0.68~0.70 → **0.46~0.51 ms/프레임**, bodies.update 2.70~2.78 → 2.41~2.70, 스크립트 5.33~5.49 → 4.91~5.40 (잡음 ±5%). 안 건드린 것: figureAnim (몸 하나 0.06ms, 가지·딕셔너리 많은 JS 이식이라 구간별 0.02 이하, 위험 대비 이득 작음), 클립 층 (0.03~0.05, 뼈마다 엔진 호출).
