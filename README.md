# Tetrafall (가칭)

3D 폴가이즈식 PC 웹 대전 게임 1단계 프로토타입.
6×6×12 격자 필드에 하늘에서 테트리미노가 떨어지고, 플레이어끼리 서로를 **압사·낙사**시켜 마지막 생존자가 이긴다.

1단계의 목적은 하나: **"이 규칙에서 압사가 실제로 일어나는가"** 검증.
합격선: 누적 **사망 중 압사 비율 50% 이상** (2026-10-20 재정의).
처음 합격선 "판당 압사 1번 이상"은 2인·목숨 1개에서 모든 판이 압사로 끝나야 한다는 뜻이라 쓰지 않는다.

## 실행 (호스트 PC)

```bash
npm install   # 처음 한 번
npm start
```

서버가 뜨면 콘솔에 접속 주소가 찍힌다:

```
Tetrafall 호스트 서버 실행 중 (포트 3000, 틱 30Hz, 인원 2)
이 PC에서:        http://localhost:3000
다른 PC에서 (Wi-Fi): http://192.168.0.12:3000
```

- 호스트 PC도 브라우저로 `http://localhost:3000` 에 들어간다 (먼저 들어온 사람이 호스트).
- 다른 PC는 같은 네트워크에서 브라우저로 `http://<호스트IP>:3000` 에 들어간다.
- **2~4명**이 함께 할 수 있다. 2명 이상 모이면 호스트 화면에 **시작** 버튼이 생긴다 (Enter 로도 됨). 더 기다렸다가 눌러도 된다. 판이 끝나면 같은 자리에 **재시작** 버튼 (역시 Enter).
- 판마다 시작 전에 3·2·1 카운트다운 (그동안 시작 위치에서 시선만 돌릴 수 있음). 판이 끝나면 "P2 승리!" 큰 글씨.
- 최대 인원은 `shared/config.js` 의 `MAX_PLAYERS` (기본 4, 시작 위치가 8개라 최대 8). 꽉 차면 "방이 꽉 찼습니다"가 뜬다.
- 판 진행 중에 들어온 사람은 그 판은 관전하고 다음 판부터 참가한다.
- 호스트는 판 사이(대기·판 종료)에 왼쪽 **플레이어 관리** 칸에서 사람·봇마다 **관전으로 / 참가로**, **내보내기**를 누를 수 있다. 관전자는 다음 판에 안 나오고 맨 위 승수·인원 계산에서 빠진다 (자리 쓰는 잠수 플레이어용). 내보낸 사람 화면엔 "호스트가 내보냈습니다"가 뜨고, 새로고침하면 다시 들어올 수 있다 (승수는 0부터). 서버 로그에 `[호스트] P2 관전으로`·`[호스트] P3 내보냄`.

### AI 봇 (혼자 할 때)

- 호스트 화면(대기·판 종료)의 **봇 추가 / 봇 빼기** 버튼. 사람 1명 + 봇 1명이면 시작할 수 있다. 판 진행 중에는 넣고 뺄 수 없다.
- 봇은 서버에서 돌고 사람과 똑같은 입력만 쓴다 (판정 특혜 없음). 그림자를 보고 0.45초 뒤에 피하고, 아이템을 먹고, 상대를 가장자리·그림자 쪽으로 밀고, 조종권으로 상대 위에 블록을 떨어뜨리고, 투사체를 쏜다. 용암이 오면 길을 찾아 높은 곳으로 올라가고, 용암 가까운 바닥으로는 내려가지 않는다.
- 세기는 `shared/config.js` 의 `BOT_*` 상수: 반응 시간 `BOT_REACTION_MS`, 밀치기 간격 `BOT_PUSH_INTERVAL_MS`(낮을수록 공격적), 조준 오차 `BOT_AIM_ERROR_RAD`.
- 사람이 모두 나가면 봇도 빠진다.
- **봇이 낀 판은 합격 판정에 쓰지 않는다.** 압사 비율이 봇의 회피 실력에 크게 좌우된다. 로그에 `2인(봇 1) 판` 처럼 따로 찍힌다.
- 방화벽이 3000 포트를 막으면 열어주거나 `PORT=8080 npm start` 처럼 포트를 바꾼다.
- 빌드 과정 없음. 서버·클라이언트 모두 순수 JS ES 모듈. three.js 는 `node_modules` 에서 그대로 서빙.

## 조작

| 상황 | 키 |
|---|---|
| 이동 / 점프 / 대시 | WASD / Space / Shift |
| 시점 | 마우스 (화면 클릭으로 Pointer Lock) |
| 밀치기 (근접 넉백) | 좌클릭 |
| 핫바 칸 고르기 (1 쌓기 블록 · 2 투사체/설치 블록 · 3 폭탄) | 1, 2, 3 / 마우스 휠 |
| 고른 칸 쓰기 | 우클릭 |
| 설치 블록 1×2 방향 (앞 ↔ 옆) | Q, E |
| 블록 조종 중: xy 이동 / 수직축 회전 / 하드드롭 | 방향키 / Q, E / Enter |

조종 중에는 카메라가 하늘 시점(직교 탑다운)으로 0.7초 동안 날아오르며 바뀐다. WASD 로 캐릭터는 계속 움직일 수 있지만 대시·밀치기·발사는 무시된다. 8초 안에 안 떨구면 자동 낙하.
하늘 시점에서 WASD 는 화면 기준이다 (W = 화면 위). 마우스로는 캐릭터가 돌지 않는다.

## 화면 표시

| 표시 | 뜻 |
|---|---|
| 위쪽 하늘색 배너 "조종권 보유: N초 후 하늘 시점으로 전환" | 조종권을 먹었고, 지금 떨어지는 블록이 끝나면 내 차례 |
| 위쪽 배너 "블록 조종 중 N초" (3초 남으면 빨강) | 조종 중. 남은 시간과 키 |
| 화면 노란 번쩍 + "P1의 밀치기/투사체에 맞음!" | 내가 넉백 맞음 |
| 캐릭터가 흰색으로 깜빡임 | 그 캐릭터가 경직 중 (추가 넉백 무시) |
| 빨갛고 큰 조준점 + "투사체 ×N" | 투사체 보유. 우클릭 발사 |
| 하늘 시점의 화살표, 흰 고리 | 각 캐릭터가 바라보는 방향, 흰 고리가 나 |
| 화면 빨간 번쩍 | 내가 사망 |

대기 화면·판 종료 화면에 조작법이 크게 뜬다.

## 규칙 요약

**2단계 (2026-10-20~):** 필드 10×10, 높이 16. 판이 길어질수록 블록이 빨라지고 동시에 여러 개(최대 4개) 떨어진다.
쌓인 블록의 평균 높이가 1칸이 되면 **용암**이 필드 아래에서 16초에 1칸씩 올라온다 (닿으면 즉사, 사망 원인 '용암'). 쌓인 지형을 타고 위로 올라가야 산다.
필드 밖으로 밀려 떨어지다 용암에 닿으면 '낙사'로 센다.
조종 중인 블록은 보라색이라 누가 노리는지 보인다.
맵: 호스트가 대기 화면에서 고른다 — 무작위(기본) · 평지 · 피라미드(가운데 언덕) · 계단(양쪽 가장자리) · 그릇(가운데 낮고 가장자리 3층) · 나선 계단(바깥 두 줄을 돌며 0→5층) · 기둥 숲(2층 기둥 9개, 가운데 3층) · 요새(모서리 3층 탑, 2층 성벽). 어느 맵이든 시작 위치에서 걸어서 맨 위까지 갈 수 있다.
이름: 대기 화면 입력칸 (최대 8글자, 브라우저가 기억, 판 사이에만 바뀜). 머리 위·맨 위 승수·승리 글씨·알림에 이 이름이 보이고, 왼쪽 위엔 `재혁 (P1)` 처럼 둘 다. 서버 로그는 P1·P2 그대로 (분석용). 용암은 시작 지형을 빼고 더 쌓인 높이로 판단.
아이템 (필드에 2개까지, 6초마다): **망치**(주황 상자, 3번 맞힐 동안 좌클릭이 2배로 밀고 1.2초 기절, 빗나가면 소모 안 함) · **점프력 상승**(초록 원뿔, 8초 동안 2칸 벽도 넘음) · **유령화**(흰 고리, 6초 동안 블록 통과·위로 뚫고 올라가 그 위에 섬, 압사는 당함) · **투사체**(빨간 공) · **설치 블록**(노란 상자, 1×2 를 2개. 2번 칸 우클릭으로 조준한 곳(최대 4칸) 3칸 위에서 떨어짐. 그림자가 보이고, 밑에 있으면 압사, 착지한 칸 바로 옆이면 충격파로 망치급 넉백 + 피해 40%. 던진 사람은 충격파 면제. Q/E 로 앞 ↔ 옆. 투사체와 2번 칸을 같이 써서 나중에 먹은 쪽만 남음) · **폭탄**(검은 공, 1개. 3번 칸 우클릭으로 조준한 곳에 놓이고 1.5초 깜빡이다 터져 3×3×3 블록(시작 지형 포함)을 부수고 2칸 안의 사람을 날림 + 피해 40%, 던진 사람 면제). 조종권(하늘색)은 따로.
**핫바**: 1 쌓기 블록(판마다 5개, 마크처럼 조준한 블록 면에 1×1 을 바로 붙임, 사거리 3칸, 사람이 있는 칸엔 못 놓음) · 2 투사체 또는 설치 블록 · 3 폭탄. 아이템을 먹으면 그 칸으로 자동 전환. 좌클릭은 칸과 상관없이 밀치기.
**HUD**: 화면 아래 가운데에 내 피해 %(크게, 맞으면 커졌다 줄어듦)와 버프(망치·점프·유령·대시), 그 아래 핫바. 경직되면 조준점 아래 빨간 "경직!" + 화면 가장자리 붉게.
화면 맨 위에 판 승수 (2명이면 `재혁 3 : 1 민수`, 3명 이상이면 `재혁 3 · 민수 1 · P3 0`). 서버가 켜져 있는 동안 쌓이고, 나간 사람 것은 사라진다. 서버 로그에도 판마다 `승수:` 줄.
**피해 %** (대난투식): 맞을 때마다 쌓이고(밀치기 +10, 망치 +25, 투사체 +20, 충격파 +40) 판 내내 안 줄어든다. 수평 넉백 = 기본 × (0.7 + %/100), 0% 에선 예전의 0.7배로 시작해 30% 에서 예전과 같아짐. 머리 위에 숫자(흰색 → 노랑 → 빨강), 내 HUD 에도. 압사·용암은 % 와 상관없이 즉사.
타격감: 명중하면 때린 쪽·맞은 쪽이 0.09초 멈칫한 뒤 날아간다. 효과음(브라우저 합성, 첫 클릭 뒤부터), 파편·충격파, 맞은 캐릭터 찌그러짐, 화면 흔들림, 1인칭 팔 휘두르기, 명중 표시(X).

아래는 1단계 때 규칙 (수치는 `shared/config.js` 가 최신):

- 테트리미노(평면 7종)가 z=12 에서 0.35초에 1칸씩 내려온다 (12칸 4.2초). 착지 1초 뒤 다음 블록. 착지 3초 전부터 착지 칸에 그림자.
- 블록 셀이 플레이어와 겹치는 순간 **압사**. 필드 밖으로 떨어지면 **낙사**.
- 6×6 한 층이 꽉 차면 그 층이 사라지고 위의 블록·플레이어·아이템이 한 칸 내려앉는다.
- 조종 안 된 자동 블록은 완전 무작위가 아니라 **가장 낮은 층을 클리어하는 쪽으로 유도**된다 (모양·회전·위치를 가중 무작위로 고름).
  블록만 떨어뜨리면 20블록 안에 약 72% 확률로 층 클리어. 세기는 `CLEAR_BIAS` (0 이면 예전처럼 완전 무작위)
- 조종권 아이템(하늘색)을 먹는 즉시 조종 시작. 자동 블록이 떨어지는 중이면 그 블록이 하늘로 올라가 내 것이 된다.
  남이 조종한 블록이 떨어지는 중이면 그게 착지한 뒤 다음 블록을 조종한다. (`CONTROL_TAKEOVER: false` 면 예전처럼 항상 다음 블록)
- 넉백 아이템(빨강)을 먹으면 투사체 1발.
- 넉백을 맞으면 0.5초 경직. 경직 중엔 조작 불가, 추가 넉백 무시.

## 튜닝 상수

**`shared/config.js`** 한 파일. 낙하 속도, 조종 시간, 넉백 세기, 경직 시간, 이동 속도, 아이템 재스폰 시간, 인원 수 등 전부 여기.
바꾼 뒤 `npm start` 를 다시 하면 된다 (클라이언트는 새로고침).

## 디버그 로그 (합격선 측정)

서버 콘솔에 판마다 찍힌다:

```
===== ROUND 3 종료 | 길이 2:41 | 승자: P2 =====
  사망: P1 압사@2:41
  이번 판: 압사 1 / 낙사 0
  누적 3판: 압사 2 (판당 0.67) / 낙사 1
  누적 사망 중 압사 비율: 67% (합격선 50% → 합격선 이상)
```

브라우저 왼쪽 위에도 누적 압사 비율이 보인다. 서버를 끄면 누적이 0 으로 돌아간다.
인원이 다른 판이 섞이면 `3인 판 4판: 압사 2 / 낙사 3 → 40% ...` 처럼 인원수별 비율도 따로 찍힌다. 합격 판정은 같은 인원끼리 비교한다.

그 외 사망 순간(원인·시각·위치), 아이템 획득, 조종 시작/하드드롭/자동 낙하(8초 초과·조종자 사망 구분), 밀치기·투사체 적중과 경직 무시, 층 클리어도 한 줄씩 찍힌다.

## 구조

```
server/index.js   정적 파일 + WebSocket + 30Hz 고정 틱 루프 (npm start 진입점)
server/game.js    게임 상태의 권위: 격자, 블록 낙하, 플레이어 AABB 물리, 넉백, 압사·낙사, 층 클리어, 로그
shared/config.js  튜닝 상수 전부
shared/pieces.js  테트리미노 모양·회전
client/main.js    WebSocket, 입력 전송, HUD, 렌더 루프
client/render.js  three.js 장면 (단색 블록, 1인칭 / 하늘 시점 카메라)
client/input.js   키보드·마우스 (Pointer Lock)
test/game.test.js 서버 규칙 단위 테스트 (npm test)
```

클라이언트는 입력만 보내고 서버 상태를 그대로 그린다 (예측 없음). LAN 전제.
