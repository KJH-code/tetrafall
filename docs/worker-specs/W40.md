## 할 일 (먼저 현재 contact sheet → 제작 → 전후, 품질 모자라면 보류+이유)
1. **2차 모션 뼈 (천·망토·코트)** — 닌자 목도리 방식을 3명에게: `tools/blender/tripo/` 의 `ninja_scarf.py` 를 일반화 (`cloth_bones.py`): 대상 천 부분 정점을 골라 **뼈 체인 2~4개** (뿌리 = 어깨/척추/골반 뼈 아래) 를 만들고 가중치 (천 정점 → 체인, 몸 정점은 그대로, 경계는 부드럽게), glb 재생성 (stage + 판 LOD 3단계 모두 같은 뼈 이름·가중치, W31 `relod` 파이프라인·`relod_merge.mjs`·`maskbake` 와 호환 — LOD 에 스킨 가중치를 옮기는 단계 포함). 후보: 사냥꾼 **초록 망토** (뒷자락 3 체인), 갈고리 **코트 자락** (뒤·양옆 3 체인), 탱크 **붉은 목도리 꼬리 + 허리 앞 천** (2 체인). `chars/ext_cloth.gd` verlet 설정을 `ext/*.json` 의 `cloth` 로 (길이·감쇠·중력·바람/이동 반응, 닌자 값 참고). 맞아 날아가면 끌려다니고 달리면 뒤로 날리고 서면 늘어지게. **스킨이 찢기거나 몸을 뚫지 않게** 자세 시험 (팔 들기·쪼그림·대시·평타·점프, `pose_sheet.gd`·`model_audit.py`). 판 LOD 에서도 동작. 비용: 뼈 추가가 CPU (Ext.sync 뼈 수·verlet 점) 를 얼마나 늘리는지 `--budget` 전후 표 (먼 몸은 천 시뮬 건너뜀 `pose_lod` 거리 기준).
2. **시선·머리 추적**: 내 몸 (3인칭)·남의 몸에서 머리가 **이동 방향/조준 방향/가까운 적**을 부드럽게 쳐다봄 (척추 가산 회전, 한계 각 ±35°, `figure_motion` 규칙·판정 불변, 클립 위에 가산, 맞음·KO·도발 중엔 끔). 닌자·탱크·사냥꾼·갈고리 모두 (뼈 이름 `Head`/`Neck`/`Spine*` 공용). 예전 코드 몸은 그대로.
3. **1인칭 팔을 3인칭 클립 곡선으로 구동 (가능하면)**: 지금은 viewmodel 이 코드 관절을 베끼고 W38 `act_swing` 이 가산. 새 모델의 공격·스킬 클립에서 **오른/왼 팔 뼈 회전 (어깨·팔꿈치·손목)** 을 샘플해 viewmodel 팔 (`tank_vm`·`hunter_vm`·`hook_vm`·`ninja_vm` 닫힌 팔) 에 적용하는 길을 시험 (구조: viewmodel 쌍둥이 몸의 팔 뼈에 같은 클립 트랙 재생 — 1인칭 쌍둥이는 `pose` 가 안 불려 `_process` 로 맞춤하니 그 자리). 시점·FOV 때문에 어색하면 가산 비율로 섞기. 안 되면 보류+이유. 전후 1인칭 프레임 (윈드업·타격·회복).
4. **착지·숨쉬기·정지 자세 다듬기**: 착지 (`land` 클립 + 수직 속도에 비례한 무릎 굽힘·상체 숙임 가산), 정지 숨쉬기 (척추·어깨 아주 작게, 2~4초 주기, 캐릭터마다 위상 달리), 무기 무게 (탱크 해머·사냥꾼 소총 어깨 처짐) — 가산 클립 또는 코드 가산. 과하지 않게 (판정·`figure_motion` 불변).
5. **맞음 반응 차이**: 맞은 방향 (앞/뒤/옆) 에 따라 움찔 방향을 달리하고 (W38 은 세기·방향 가산), 치명타는 짧은 몸 꺾임 + 무기 쥔 손 흔들림, 방어구 깨짐 (탱크) 은 방패 쥔 팔 반동. 래그돌 모터가 약하면 빠지는 규칙 유지.
6. **타격 끝 짧음 추가 개선** (사냥꾼 베기 계열 −0.75~−1.02m, 갈고리 −0.56~−1.02m): 클립 타격 순간의 몸 내딛기·상체 회전·팔 최대 뻗기를 키우고 소총을 앞으로 내미는 자세 (서버 이동·히트박스 불변), `tools/hit_reach.gd` 전후 표.
