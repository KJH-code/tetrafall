# 캐릭터 설계

C 설계 세션 산출물. 구현은 A(서버)·B(화면)가 한다. 수치는 전부 초안이고 실제 값은 봇 판·사람 테스트로 맞춘다.

## 0. 설계 틀

새 캐릭터는 이 틀부터 채운다. 남의 **기술**은 가져오지 않고 **원리**만 쓴다.

### 0.1 지킬 방향 (재혁)

| 항목 | 내용 |
|---|---|
| 톤 | 속은 격투, 겉은 병맛 (TABS). 판정은 AABB 그대로, 몸만 흐물 |
| 콤보 | 운이 아니라 실력. 캐릭터마다 고유 콤보·장단점 |
| 평타 | 지상·공중이 다름 |
| 금지 | 운빨, 억까. **콤보 마무리로 상대를 블록 밑에 보내 압사시키는 연계** |
| 정체성 | 블록·지형이 바뀌는 필드에서 싸움 |
| 탱크 | 버서커 아님. 반격형 (돈키호테 원리) |
| 로스터 | 초보 추천캐(연타 + 생존기) 최소 1명 |

### 0.2 축

| # | 축 | 값 |
|---|---|---|
| 1 | 콤보 형태 | 긴 연계 / 짧은 폭딜 / 견제 |
| 2 | 시작기 | 지상 평타 / 공중 스킬 / 원거리 적중 후 접근 / 돌진 / 설치물 |
| 3 | 적중 보상 | 스택·표식 / 쿨 감소·초기화 / 이속 / 없음 |
| 4 | 필살기 자원 | 게이지 / 스택 / 쓴 만큼 셈 / 강화 모드 / 특정 행동으로만 충전 |
| 5 | 이동·생존 | 적중형 순간이동 / 설치형 순간이동 / 돌진 / 은신 / 없음 |
| 6 | 빗나갈 때 벌 | 큼 / 작음 |
| 7 | 숙련 | 바닥(시작 난이도) · 천장(잘하면 얼마나 셈) |
| 8 | 약점 방향 | 원거리에 약함 / 붙으면 약함 / 쿨 빠지면 약함 |
| 9 | **지형 활용** (우리 고유) | 블록을 만듦 / 블록을 씀 / 무관 |
| 10 | 남에게 주는 영향 | 없음 / 표식(모두의 표적) / 장판(누구나) / 폭탄화 |
| 11 | 아머·방어 | 없음 / 슈퍼아머(깨지는 조건) / 패리 / 피해 감소 |

규칙: 4명이 **2·3·4번 축에서 같은 값을 쓰지 않는다.** (지금은 4명 다 지상 평타 시작 · 적중 보상 없음 · 게이지라서 캐릭터 차이가 수치뿐)

### 0.3 유형

| 유형 | 축 조합 | 참고 (스매시 레전드) |
|---|---|---|
| 돌파형 | 짧은 폭딜 + 돌진 + 빗나가면 벌 큼 | 스노우, 레드, 피터 |
| 연계형 | 긴 연계 + 공중 시작 + 숙련 천장 ↑ | 쿠레나이, 우치, 신디 |
| 사냥꾼형 | 스택 쌓기 → 터뜨림 | 구미, 마스터 캣, 하멜린 |
| 지형·설치형 | 설치물로 공격·이동·엄폐 | 브릭, 아오이, 빅터 |
| 디버프·제어형 | 상대 행동을 제한 | 파르페, 앨리스, 라푼젤 |
| 버티기(반격)형 | 맞을수록 이득, 방어 중 반격 | 돈키호테, 카이저 |
| 추적형 | 원거리 적중 → 접근 | 자베르, 알리, 오공 |
| 견제형 | 원거리로 공간 잡기 | 로빈, 후크 |
| 서포터형 | 아군 지원 | 골디, 옥타비아 |
| 카운터형 | 상대 공격에 맞춰 받아침 | 몰리, 스피로 |

### 0.4 서포터·디버프 원칙

팀전은 있지만(`server/game.js` `teamMode`) 기본은 개인전이고 얼마나 할지 모른다.

| 원칙 | 이유 |
|---|---|
| 순수 서포터(회복·아군 버프만) 금지 | 개인전에서 쓸모없음. 피해 %는 넉백 배율이라 회복도 약함 |
| 지원 효과는 **팀전이면 아군, 개인전이면 나 또는 누구나** | 예: 장판·길은 들어온 누구나, 표식은 때린 누구나 이득 (골디 원리) |
| 디버프는 "상대가 **블록·지형을 다루기 어렵게**" 쪽 | 둔화, 점프 감소, 넉백 더 받음. 정체성과 맞음 |
| 시야 방해 금지 | 블록 그림자를 가리면 압사 억까 |
| 기절은 0.5초 이하 + 맞기 전 예고 | 억까 방지 |

### 0.5 공통 시스템 후보 (캐릭터와 별개, 재혁 결정 필요)

| 후보 | 상태 | 메모 |
|---|---|---|
| DI (맞을 때 방향키로 넉백 방향을 조금 틂) | 재혁 찬성 | 입력은 이미 서버로 감. 예측 없어도 됨 |
| 필살기 시전 순간 슈퍼아머 (전원) | 제안 | "스킬 씹힘"이 R에서는 사라짐. 강한 공격에 깨지는 조건 (티문 원리) |
| 공중 스킬을 지상 스킬과 다르게 | 재혁 찬성 | 쿠레나이 바람의 술처럼 |
| 콤보 끝 무적 0.3초 | 유지 제안 | 낙사 71%라 스레처럼 끝까지 맞으면 콤보 하나 = 죽음 |
| 스펠 (판 전에 고르는 공용 부가 효과: 고정딜, 도약, 1초 무적, 필살기 재충전 등) | 보류 | 스레 시스템. 캐릭터 정하고 나서 |

### 0.6 재혁 취향 (편향 확인용)

| 좋아함 | 이유 | 축으로 |
|---|---|---|
| 빅터 | 지뢰 깔고 한 번에 펑, 뇌지컬, 재능 연계로 천장 높음. **공격적으로** 씀: 스킬·스킬·궁, 공중 평타·스킬·평타. 공격 오면 공중 스킬로 피하고 남은 지뢰로 반격 | 설치형인데 설치물이 **콤보 부품 + 반격 자원**. 니가와 아님 |
| 후크 | 궁 뒤에 스킬 + 각성 + 스펠 + 재능이 겹쳐 딜이 미침 | 강화 창 + 자원 겹치기 |
| 구미 | 표식 있는 상대를 궁으로 맞히면 궁이 다시 참 → 콤보 아니어도 평·궁 연발로 다 쓸어버림 | 사냥꾼형 + 조건부 필살기 재충전 |
| 나르샤 | 위에서 나만의 게임 | **우리 게임에는 안 넣음** (재혁) |

| 싫어함 | 이유 | 피할 것 |
|---|---|---|
| 티르핑 | 사기, 밸붕 | 대가 없는 장점 |
| 니가와 캐릭터 | 재미없고 비매너 | 설치물·방어가 대기 플레이가 되는 구조 |
| (예전 생각의) 탱크 | 손맛 없음 | 탱크는 반격형으로 |

편향 경고: 좋아하는 셋 다 숙련 바닥·천장이 높다. 초보 추천캐는 따로 의도해서 만든다.

### 0.7 억까 체크리스트 (새 기술마다, 맞는 쪽 입장에서)

억까 = "맞는 쪽이 할 수 있는 게 없었다". 지는 건 괜찮고, 할 일이 안 보이는 게 문제. **세면 너프, 억까면 구조를 고친다** (숫자만 깎아서는 억까가 안 없어짐). 만든 사람에게는 억까로 안 느껴지니 친구 말이 기준.

| # | 질문 | "아니오"면 |
|---|---|---|
| 1 | 온다는 게 **보이나**? | 예고 자세·번쩍·바닥 표시 |
| 2 | 보고 **피할 시간**이 있나? (반응 약 0.2초 + 핑) | 준비 시간 늘리기 |
| 3 | 못 피했을 때 **할 수 있는 게** 있나? | 탈출 수단 (DI 등), 짧은 경직 |
| 4 | **운**이 아니라 실력으로 결정되나? | 랜덤 빼기 |
| 5 | 조작을 **0.5초 넘게** 뺏나? | 줄이기 (점프 봉인·입력 무시는 압사로 이어져서 안 씀) |
| 6 | 결과가 **실수에 비해** 적당한가? | 피해·넉백 줄이기, 즉사 연계 금지 |
| 7 | 죽고 나서 **왜 죽었는지** 아나? | 효과·관전·킬 표시 |

| 억까 종류 | 우리 게임 예 |
|---|---|
| 못 봄 | 이동 스킬 준비 0 → 지상 150ms + 번쩍 |
| 못 피함 | 탱크 R 예고 0.5 → 0.7초 |
| 대응 수단 없음 | 하드 카운터 (4.1 상성) |
| 운 | 블록이 내 위에 떨어짐 → 낙하 속도 감속 (2026-10-24) |
| 조작 뺏김 | 닌자 5연타 묶기, 점프 봉인 (버림) |
| 결과가 너무 큼 | 콤보 마무리로 블록 밑 압사 (금지), 분노 상한 없음 (볼 것) |
| 이유를 모름 | 관전이 나를 죽인 사람부터 따라감 ✅ |
| 판정이 화면과 다름 | 핑 → 원거리는 보이는 느린 탄 |

### 0.8 특수 판정 규칙 (2026-10-26)

| 규칙 |
|---|
| **특수 판정(잡기·관통·면역 무시·즉시 판정)에는 대가가 꼭 하나 이상**: 약한 피해 / 긴 예고 / 짧은 사거리 / 조건 |
| 특수 판정 기술을 버프할 때 **대가를 지우는 쪽으로는 안 함** |

예: **티르핑** (스매시 레전드, 재혁) — 딜이 셈 + 면역을 뚫음 + 잡기 판정. 대가 없는 장점(메타 나이트) + 맞는 쪽이 할 게 없음(베요네타)이 겹침 → "사기, 밸붕".

| 지금 특수 판정 | 캐릭 | 대가 |
|---|---|---|
| 끌어오기 (잡기류) | 갈고리 F | 좁은 각, 빗나가면 쿨 8초, 피해 없음 |
| 즉시 판정 여러 명 | 사냥꾼 R | 표식 필요, 0.5초 예고, 블록이 막음, 게이지 2배 |
| 아머 (경직 무시) | 탱크 F·R | 마무리 타·R 에 깨짐, 피해는 받음 |
| 블록 관통 | 대포수 R | 직선만 |

| 사기 패턴 (사례) | 고치는 범위 |
|---|---|
| 대가 없는 장점 (메타 나이트, 스매시 X) | 대가 붙이기 |
| 맞는 쪽이 할 게 없음 (베요네타 사다리 콤보, 스매시 4) | 구조 (경직·연결) |
| 조합이 강함 (오버워치 GOATS → 역할 고정) | 시스템 |
| 쉬운 게 최강 (포트나이트 B.R.U.T.E → 삭제) | 천장 낮추기 |

| 갈고리 | 낫배드. 블록 걸기·공중 스핀이 안 보이고 체감 안 됨 | B: 날아가는 사슬 + 걸린 블록 번쩍, 스핀 원 궤적, 끌려갈 때 바람 줄 |
| 전체 | 블록이 주인공인지 모르겠음 — **모션이 없어서 체감 안 됨** | B: 블록이 움직이는 순간마다 모션·효과 (건축가 폭발, 탱크 솟는 땅, 갈고리 뽑기·박힘, 닌자 블록 닿기) |

### 5.1 블록 주스 (B, 2026-10-26 재혁 승인)

사람 타격에는 멈칫·흔들림·파편이 있는데 블록에는 없음 → 블록 일마다 **예고 → 순간 → 여운** 세 겹. 원칙: 중요할수록 크게, 남 것은 작게·내 것은 크게, 소리가 제일 싸고 셈 (같은 소리도 높낮이 조금씩 랜덤).

| 블록 일 | 예고 | 순간 | 여운 |
|---|---|---|---|
| 테트리미노 착지 | 그림자 진해짐 | 쿵 소리 + 근처면 화면 살짝 흔들림 + 바닥 먼지 | 먼지 가라앉음 |
| 건축가 블록 폭발 | 금 가며 부풂 | 펑 + 파편 | 연쇄는 칸마다 약 0.05초 차이로 차례로 (리듬) |
| 탱크 솟는 땅 | 땅이 떨림 | 흙 튀며 솟음 | 가라앉을 때 먼지 |
| 갈고리 R 뽑기 | 사슬 팽팽 | 찌익 뜯기는 소리 + 흙 덩이 | 빈자리 먼지, 박힐 때 쾅 |
| 대포수 블록 부숨 | — | 와장창 + 큰 파편 | 파편이 바닥에 튐 |
| 닌자 떨어지는 블록 닿기 | — | 반짝 + 작은 "탁" | 점프 회복 표시 |
| 압사 | 그림자 | **납작하게 찌그러짐** (병맛, 왜 죽었는지 바로 보임) + 큰 쿵 | 납작한 채로 잠깐 |

확인: 소리 끄고 / 효과 끄고 / 남이 하는 걸 보며 4명 엉켰을 때 읽히는지.
참고 (총괄 판단): 인터넷에서 "조작이 무겁다"가 나오면 **내 입력 반응(휘두르는 소리·작은 몸짓)만** 누른 순간 화면에서 내는 방법이 있음. 결과는 서버 그대로. "클라 예측 없음" 규칙에 걸리는지는 총괄이 정함.
