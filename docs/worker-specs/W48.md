## 할 일
1. **한 줄 '성능 보고서' 생성기** (`core/report.gd`, 순수 계산 + 수집): 한 판 (또는 지금까지) 의 다음을 **하나의 짧은 텍스트 (≤ 1500자, 붙여 넣기 쉽게)** 로 만든다 — ① 버전 (게임 빌드 태그·커밋), 렌더러 이름 (Compatibility/Mobile/Forward+), GPU 이름·내장 여부, 해상도·UI 배율·3D 배율 (적응형 현재/최저)·화질, OS, ② 프레임: 평균 FPS·1% low·최악 프레임 ms (판 중), CPU 스크립트/렌더 ms, 영상 메모리, ③ 히치 요약 (`core/hitch.gd` 의 '원인 상위 5개·최악 ms·시점' — 판 요약 줄), 해상도 변경 횟수, ④ 모션 QA 팝 상위 5개 (`core/motion_qa.gd` 가 켜져 있으면; **꺼져 있어도 비용 0 인 가벼운 카운터를 판 중 기본 켜서** (팝 카운터만, 노드 없이) 최소한 '캐릭터별 팝 수' 는 남기게 — 비용 측정해서 0.05ms 이하일 때만), ⑤ 캐릭터·인원·맵·모드, 판 길이, ⑥ 켜진 옵션 (`--old-gait`·`--no-w43` 등 비기본 인자). 개인정보 없이 (사용자 이름·경로의 `C:\Users\<이름>` 제거 — `%APPDATA%` 로 치환).
2. **결과 화면 버튼 '성능 보고 복사'**: 판이 끝나 결과 판 (`ui/results.gd`) 이 뜰 때 작은 버튼 한 개 (대기실 판에도) — 누르면 위 텍스트를 클립보드에 복사하고 '복사됨 — 채팅에 붙여 넣어 주세요' 토스트. 키 하나 (기본 F4? 키 설정 `keys.gd` 에 `report`) 로도 판 중 어디서나 복사. 판 요약은 **판이 끝날 때 자동 계산** (렌더 비용 없이). 'UI 가 작다' 는 이슈 방지: 버튼은 UI 배율 따름.
