# W54 — 사거리·공격 타이밍을 모션에 맞추기 (2026-11-14)

기준 = v0.1.21 (6ba2e4d). **1단계: 측정·제안서 (코드 수정 전).** 도구 `godot/client/tools/w54_reach.gd` (hit_reach.gd 확장, 가상 시계로 결정적 — 같은 수치 2회 확인, 원자료 `reach_before.csv`).

## 측정 방법

- 평타마다 몸이 게임에서 하는 길 그대로 (`_figure_anim` → `Ext.sync(st)`) 자세를 만들고, 스킨 적용한 정점 중 **몸 중심에서 앞(+x)으로 가장 먼 점** (무기 끝·주먹·발끝) 을 잼. 표본: 준비 끝 = **서버 판정 순간**, 타격 u 0·.25·.5·.75·1 (클라 `FIGURE_STRIKE_S` = 70ms), 회복 .15·.4.
- 서버가 치는 가장 먼 상대 앞면 = `range − PLAYER_HALF` (`range` 기본 `PUSH_RANGE` 1.8, 갈고리 탕 2.0). `step` (판정 순간 때리는 쪽이 앞으로 나가는 거리) 은 플레이어 위치가 실제로 옮겨 가므로 **보이는 끝과 서버 앞면 양쪽에 같이 더해져 비교에서 빠짐** (옛 `hit_reach.gd` 는 서버 쪽에만 step 을 더해 차를 0.3~0.8 부풀렸음).
- **차 = 보이는 끝 − 서버 앞면 (m)**. 음수 = 서버는 맞는데 무기가 아직 안 닿음 ("닿기 전에 맞음"), 양수 = 무기가 더 나가 있음.
- 소프트웨어 렌더 환경의 뼈 포즈 수치 (xvfb 없이 헤드리스, 포즈는 정확, 음영·체감은 못 봄).

### 읽는 법

- **시간 어긋남이 더 큼**: 사냥꾼 내려 베기·찔러 넣기·베기, 갈고리 내려치기·휘두르기·주먹 은 **타격 끝 (판정 +70ms) 에는 서버 앞면에 닿거나 넘는데 판정 순간엔 0.7~1.2m 뒤** — 서버는 준비가 끝나는 순간 (u=1) 판정하고 클립의 휘두름은 그 뒤 타격 구간 (70ms) 에 시작 → 눈에 보이는 타격이 판정보다 70~250ms 늦음. 최대 시각이 판정 후 100~250ms 인 것 (사냥꾼 찔러 넣기 250ms, 갈고리 주먹 190ms) 은 회복 구간에서 더 나가는 클립 (끝 +0.4~0.8m 오버슛).
- **거리 어긋남 (타격 끝에도 모자람)**: 닌자 전부 (단검·발차기가 짧음, −0.38~−0.71), 갈고리 탕 (−0.79, 사거리 2.0 인데 총이 짧음), 탱크 방패 올려치기 (−0.70, 방패를 위로 들어 앞으로 안 나감), 갈고리 스핀 −0.48, 사냥꾼 반대 베기 −0.55.
- 탱크 주먹만 판정 순간에 이미 맞음 (0.00).
- 서버 범위는 중심 거리 기준이라 상대가 가까이 있으면 (기본 `BASIC_STEP_GAP` 0.6 에서 멈춤) 훨씬 덜 모자라 보임 — 이 표는 **판정 가장자리 (최대 사거리) 에서 맞은 경우** 의 최악 값.
- 타격 구간의 클립 속도: 클립 눈금 0.10초 (m0→m1) 를 `FIGURE_STRIKE_S` 0.07초에 지나감 = 1.43배속 (W52 가 센 '강한 팝' 의 원인).
