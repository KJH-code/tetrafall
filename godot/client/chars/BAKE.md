### .glb 안

```
<id> (장면 뿌리)
└ frame                       게임 좌표 (앞 +x, 왼쪽 +y, 위 +z) → glTF/고도 Y 위 (x 축 −90°, body.gd 예전 frame 과 같음)
  ├ body ─ rig ─ parts ─ … ─ hips ─ waist ─ … shoulder_R ─ elbow_R ─ hand_R …   관절 나무 (자리·회전·크기 = JS 노드 그대로)
  │        └ <주인>__m<재질>[_ns]       나머지 조각을 주인 노드 아래 재질·그림자마다 하나로 합친 잎 (1인칭 팔용 조각 몸)
  └ Skeleton3D (import 가 B_<노드 번호> 뼈 나무를 바꾼 것) ─ batch   툰 조각 전부 = 정점 색 SkinnedMesh 하나 (판 몸)
```

- **남기는 노드** = refs 가 가리키는 노드 (관절·천 자락·방패·총·뿔·폼 부위·눈동자…) + 처음 숨긴 노드 + 닌자 단검 + 맨 위 + 그 조상. 코드가 자세·보이기·재질을 바꾸는 노드는 다 남음. 나머지 (안 움직이는 조각·묶음 노드) 는 주인 아래로 합침
- **이름** = body.gd 관절 이름: `hips·waist·neck·torso·shoulder_R/L·elbow_R/L·hand_R/L·thigh_R/L·knee_R/L·foot_R/L` ([0] 오른쪽·[1] 왼쪽, ragdoll.gd `upperR = shoulders[0]`), 나머지 refs 는 경로 (`flaps_0_obj`·`shields_front`·`formParts_metal_3`), 안 가리키는 노드는 `n<JS 번호>`. 고도 import 는 이름을 장면 전체에서 겹치지 않게 바꾸므로 굽기 도구가 미리 겹치지 않게 함
- **묶음 (판 몸)**: 불투명 툰·그림 없음·발광 없음·외곽선 재질 (양면 툰도 — 아래 '양면 조각'). 근육 홈 (`shade` = 피부 × 어둡게, 사람마다 색)·바드 몸통 (폼마다 재질 통째로)·광전사 눈 흰자 (분노 색) 도 따로. 뼈 = 조각 주인 노드 (탱크 27개, 예전 묶음은 조각마다 90개)
- **정점 색**: 재질 sRGB 값 (G3 batch 와 같음). 고도 import 가 glTF COLOR_0 를 '선형' 으로 보고 sRGB→선형으로 바꿔 넣어서 굽기 때 반대로 바꿔 씀 (16비트). 그래서 블렌더 등에선 색이 밝게 보임. 피부 정점은 흰색 + UV2.x = 1 → 툰 `skin_tint` (a = 1, 몸 색) 가 칠함 → **묶음 메시는 같은 캐릭터 몸끼리 같이 씀** (사람마다 색을 굽지 않음)
- **manifest** (`<id>.json`): `nodes` [{name, parent, hidden, noShadow, dagger, mat, batch}] (부모 번호 < 자식 번호, 묶음 잎은 맨 끝 = `batchStart` 부터) · `mats` (gen-bodies 재질 표 그대로 → `body._material` 이 G3 툰·basic 으로) · `refs` (새 번호) · `bones` · `stats` · `source` (JS 원본 해시)

### 고도에서 두 모양

- 판·대기실·초상 몸 (`merge` + `K.SKIN`): 묶음 잎 (manifest 끝) 은 버림, 묶음에 들어간 남긴 메시 노드는 layers 0 (자리만 — G3 batch 와 같음), `BakedBatch` 가 뼈 ↔ 노드 (`B_<번호>`). 예전 batch 처럼 `sync()` 한 번 + 매 프레임 움직이는 뼈만 `_sync_bones`
- 1인칭 팔 쌍둥이 (`merge = false`): 잎 그대로, Skeleton3D 는 버림. viewmodel 은 `twin.cd` 를 읽고, 베낄 노드는 판 몸 노드 표 안 (묶음 잎은 안 움직임)
- 래그돌 (관절 노드)·초상·대기실 큰 캐릭터·잔상 복제 (`snapshot` 이 frame 을 복제 — 뼈·묶음도 같이)·한 겹 더 (`set_overlay`)·반투명 (투명 재질에도 skin_tint)·몸 색 효과 (`_fx_colors` 는 구운 몸이면 skin_tint a 늘 1) 는 같은 길

### 양면 조각 (W13, 남은 일 1 → 끝)

JS 에서 `side: DoubleSide` 인 툰 조각 (갈고리 망토 자락·모자 챙, 바드 메탈 폼 부위, 건축가 일부) 은 굽기 도구 `twoSided` 가 **삼각형을 뒤집은 사본 (감김 반대·법선 반대) 을 같이 구워** 한 면 재질 그대로 묶음에 넣음. three DoubleSide 가 뒷면에서 법선을 뒤집어 칠하는 것과 같은 모습.
둘째 표면 (cull_disabled 재질) 을 두는 계획 대신 이렇게 한 까닭: 표면이 둘이면 툰·외곽선·반투명·skin_tint 재질이 다 둘씩 (`_fx_colors`·`_apply_opacity`·`set_overlay` 도) → 그리기 호출이 늘고 코드가 갈림. 사본은 그 조각 정점만 두 배.
결과: W7 임시 굽기 때 갈고리 12·바드 14 (외곽선까지 센 값) 로 늘던 그리기가 이제 갈고리 3·바드 4 (보이는 메시, 예전 조립 3·6 이하 — 2절 표). 예전 고도 묶음은 이 조각들을 한 면으로 묶어 뒷면이 안 보였음 → .glb 가 JS 와 같고 예전 고도와는 다름 (갈고리 모자 챙 밑면 등, 아래 화소 표의 hook 1.8%).
basic (눈 등) 양면은 고도 재질이 원래 CULL_DISABLED 라 그대로.

## 6. 외부 .glb (AI 3D 생성 — Meshy·Tripo 뼈대 모델) 를 넣는 방법

두 길이 있음. **권장 = W14 외부 모델 길** (`chars/external.gd`, 안내서 `chars/EXTERNAL.md`, `assets/models/ext/<id>.glb`): 모델 뼈대를 그대로 두고 뼈 이름을 우리 관절에 자동 매핑, 크기·발바닥·맞춤 회전·툰 재질을 입힘. body.gd 가 외부 → 구운 → 코드 조립 순서로 고름. 아래는 **구운 몸 길** (이 문서) 에 외부 모델을 넣을 때 지켜야 할 것 — 손질한 JS 몸이나, 뼈 하나에 조각이 딱 붙는 (가중치 1) 로우폴리 모델에 맞음.

### 애니메이션은 코드가 함
`figure_motion.gd`·`figure_pose.gd`·`moves.gd` 가 매 프레임 **관절 노드** (이름으로 찾은 Node3D) 의 rotation·position·visible 을 바꿈 → `_sync_bones` 가 묶음 뼈에 옮김. .glb 안 애니메이션은 안 씀 (import 에서 끔). 그래서 외부 모델은 (1) 관절 노드가 있고 (2) 쉼 자세 = JS 쉼 자세 (팔 내림·차렷, 앞 +x — T/A 포즈면 관절마다 쉼 회전을 굽기 때 노드 transform 에 넣어 둬야 함, 안 그러면 모든 동작이 T 포즈 기준으로 틀어짐) 이어야 함.

### 관절 이름 (manifest·노드 이름 = body.gd refs, [0] = 오른쪽)

| 우리 노드 | 하는 일 | Mixamo 꼴 이름 (Meshy·Tripo 자동 뼈대도 대개 이 꼴 — 실제 파일로 확인) |

### 필요한 노드·파일 (`_build_glb` 가 보는 것)
- 장면 뿌리 아래 `frame` (게임 → 고도 돌림 x 축 −90°) → `body` → `rig` → `parts` → … `hips` → 위 관절 나무. 이름이 장면 전체에서 겹치지 않을 것 (고도 import 가 겹치면 바꿈)
- 판 몸 묶음: `frame/Skeleton3D` (뼈 이름 `B_<manifest 노드 번호>`, 부모 뼈 = 가장 가까운 조상 뼈) + 그 아래 SkinnedMesh 하나 (정점 색 = 재질 sRGB 를 선형으로 바꿔 넣은 값, 피부 정점은 흰색 + UV2.x = 1, 정점마다 뼈 하나 가중치 1). 가중치가 여러 뼈에 섞인 모델 (AI 자동 뼈대는 거의 다) 은 `_sync_bones` (뼈 = 노드 자리) 로는 되지만 1인칭 쌍둥이 (조각 몸 — 관절마다 잘린 메시) 를 만들 수 없음 → 이 경우 W14 길
- manifest `<id>.json`: `nodes` (이름·부모·숨김·재질·batch 순서), `mats`, `refs` (위 이름의 노드 번호), `bones`, `batchStart`·`leafStart` — 지금은 `tools/bake-bodies.mjs` 가 JS 에서 만듦. 외부 .glb 로 하려면 .glb 노드 이름에서 manifest 를 다시 만드는 도구가 필요 (남은 일 7)
- 맞는지 확인: `test_baked` 의 `test_baked_files` (이름·뼈·메시 여부) 는 그대로 쓰이고, '예전 조립과 같음' 비교는 JS 와 모양이 달라지면 빼야 함. 이름이 하나라도 안 맞으면 `_build_glb` 가 경고 후 예전 조립으로 돌아감 (`test_baked_fallback`), `--no-glb` 로 늘 예전 조립

### 무엇을 바꾸나

- **살색·옷 칸**: 묶음 SkinnedMesh 의 사본 (캐릭터마다 하나, 몸끼리 같이 씀) 에서 정점 색과 UV2.x 만 바꿈 — 정점 수·자리·뼈·삼각형은 원본과 같음 (그리기 수·삼각형 그대로).
  피부 정점 (흰색 + UV2.x 1) 중 살은 **살색 정점 색 + UV2.x 0**, 옷 칸은 그대로 (`skin_tint` 가 플레이어 색으로). 피부가 아닌 옷 조각을 플레이어 칸으로 올릴 땐 (`promote`) 흰색 + UV2.x 1.
  피부 손을 장갑 공이 다 덮고 있는 대포수 주먹은 그 장갑 조각을 살색으로 (`bare` — 피부가 아닌 조각 → 살색, 손목 띠는 그대로).
  역할은 뼈 이름으로 (`roles`), 한 뼈에 얼굴과 모자·팔과 띠가 같이 있으면 **조각** (같은 뼈에서 이어진 삼각형 덩어리) 의 가운데 높이 (`split`)·반폭 (`wide`) 으로 — 조각을 반으로 자르지 않음.
- **눈**: 흰자·눈동자를 흰자 가운데 기준으로 `eye_scale` 배 (흰자 지름 ≤ 머리 폭의 1/3). 두 눈이 한 메시인 일곱은 메시 사본 (눈 = 삼각형으로 이어진 덩어리 — 두 흰자 공이 가운데서 겹쳐 있어 정점 y 부호로 나누면 겹친 정점이 반대쪽 눈에 묶여 한 띠로 늘어남, `eye_sides`), 광전사는 흰자 노드 크기 (자식인 눈동자·어지러움 궤도가 같이 줄어듦) + 분노 눈썹을 가까운 눈 쪽으로 같은 배율.
- **선·단**: 묶음 재질과 따로 그리는 툰 조각 (바드 몸통·건축가 체크 무늬·근육 홈…) 에 `toon_steps (0.7, 0.86, 1.0)`·림 `0.22 / 3.0`·외곽선 `G3.shared_outline(OUTLINE_THICKNESS × 0.45)`. W31 먼 거리 외곽선 (`_collect_outline`)·설정 '외곽선' 켜고 끄기도 얇은 것으로.
- **1인칭 팔 (조각 몸, c6 리뷰 F2)**: 1인칭 팔 쌍둥이 (`merge = false` — 묶음 없이 잎 조각을 그대로 그림) 는 조각마다 재질 색 하나 (피부 재질 = 플레이어 색) 라 묶음 사본을 못 씀 →
  묶음에 들어가는 조각 메시 (잎 `<주인>__m<재질>` = 주인 뼈, 남긴 메시 노드 = 제 뼈 — 정점이 그 뼈 기준 좌표라 표의 `split`·`wide` 문턱이 그대로 맞음) 마다 같은 `classify`·`paint` 로
  정점 색·UV2.x 를 넣은 사본 (`for_pieces`, 캐릭터마다 한 번·조각 몸끼리 같이 씀, 역할이 바뀌는 조각만), 그 조각들은 이 몸의 정점 색 툰 재질 하나 (`body.look_mat`, `skin_tint` = 플레이어 색 — 묶음 재질과 같은 꼴) 로 그림.
  나머지 조각·재질은 그대로 (+ 같은 툰 단·림·얇은 외곽선). 칸 (뼈마다 플레이어 색·살색·옷 색 정점 수) 이 묶음 사본과 똑같음 (테스트). 눈은 안 건드림 (1인칭은 팔꿈치 아래·무기만 그림).
  외부 모델이 붙는 몸 (PC 탱크·닌자·사냥꾼·갈고리) 의 안쪽 조각 몸은 안 그려서 뺌 — 그 1인칭 팔은 `external.gd` 길. 웹 (`--no-ext`) 은 8명 다 이 길.
- **효과**: 경직 하얀 깜빡임·발광은 그대로 `skin_tint`·`skin_emissive` → 이제 플레이어 칸에만 (외부 모델과 같음). 근육 홈 (묶음 밖, 피부 × 어둡게)·건축가 안전모 테는 예전처럼 플레이어 색에서 나옴.

### 숫자 (헤드리스, load 4 안팎이라 비율만)

- 사본 만들기 (캐릭터마다 세션에 한 번 — 그 캐릭터 몸을 처음 만들 때 얹힘): 첫 몸 만들기가 화풍 끔 1.0~3.2ms → 켬 5.6~18.6ms, 늘어난 몫 +3.4~16ms, 8명 합 66~96ms (늘어난 몫만 54~75ms).
  잰 법: `tools` 밖 확인 스크립트 (캐릭터마다 캐시를 비우고 `Body.build` 를 3번, 외부 모델 끔, 헤드리스 고도 4.7.2) 를 두 번 — load 0.14 일 때 켬 7.9~18.6ms·합 약 96ms, load 0.4 일 때 켬 5.6~11.8ms·합 약 66ms (2026-11-15).
  처음 적은 값 (3.5~10.5ms·합 약 50ms) 은 실제보다 낮았음 (c6 리뷰 F6). 둘째 만들기부터는 +0~0.2ms (예: 탱크 1.02 → 1.07ms).
  미리 데우는 길은 메뉴 초상 데우기뿐 — `?room=` 링크·재접속으로 바로 들어오면 이 비용이 대기실·판의 첫 몸 만들기에 얹힘 (입장 분할 조각으로 미리 부르기는 안 함 — 아래 '안 한 것').
- 조각 몸 사본 (1인칭 팔 쌍둥이, 내 캐릭터 하나): 그 캐릭터 쌍둥이를 처음 만들 때 한 번 1.4~2.6ms → 4.7~13.6ms (+2~12ms, 같은 조건·load 0.4), 그 뒤는 +0.1~0.5ms (재질 하나 더).
- 그리기 수·삼각형: 같음 (메시 모양·재질 수 그대로). 늘 같은 장면 (갤러리 식 8명 한 줄, `--no-ext`) 에서 `--no-look` / 켬 모두 그리기 48·삼각형 77758·물체 52. 연습 방 `--perf-log` 는 같은 빌드도 실행마다 삼각형이 19178~19812 (±1.6%) 로 흔들려 ±1% 를 못 가름. 자세 벤치 (`tools/bench_bodies.gd`) pose 합: 기본 2.63 → 2.57ms, `--no-ext` 1.18 → 1.19ms (흔들림 안).

### 안 한 것·알아 둘 것

- 1인칭 팔 (조각 몸) 의 눈은 그대로 (큰 눈) — 1인칭에선 안 그려서. 조각 몸 전체를 그리는 곳이 생기면 `Look._eyes` 를 조각 길에도.
- 화풍 사본을 입장 분할 (대기실 PSched 조각) 로 미리 만들기·원본 메시 놓기 (영상 메모리 +1.6~4.8MB) 는 안 함 — 앞은 링크·재접속 길에서 캐릭터마다 한 번 5~16ms 이득뿐이고 입장 분할을 건드려야 하고, 뒤는 `--no-look`·'끄면 예전 그대로' 가 원본을 씀 (c6 리뷰 F6).
- 얇은 판 조각 (사냥꾼 망토·갈고리 코트 자락의 바깥 면, 탱크 등 방패의 몸 쪽 면) 이 외곽선 색 (보라빛 회색) 으로 보이는 건 이 작업 전 사진에도 같음 (`--no-look` 과 화소가 같음) — 정점 색을 바꿔도 안 달라져서 색 칸 문제는 아님. 까닭은 안 캠 (외곽선 껍질로 짐작, shaders/ 는 이 작업 범위 밖).
- (c7-u1, 2026-11-16) 위의 보라 판 조각을 고침: 표의 `double` (탱크·사냥꾼·갈고리) → 그 몸의 불투명 툰 재질이 양면 (`toon_double.gdshader`) + `outline_push` 로 깊이로 민 얇은 외곽선 (`Look.outline_for`). 림은 외부 모델과 같이 지수 4 + 플레이어 색 틴트 (`RIM_TINT`·`RIM_GATE`, 묶음·화풍 재질처럼 `skin_tint` 를 가진 재질만). `Look.style(m, outline, char_id, rim_tint)` 은 캐릭터를 인자로 받음 (c7-fix F10 — 예전엔 `for_char`·`for_pieces` 가 적어 둔 정적 `Look._char` 를 읽어, 늦게 부르는 `body._apply_opacity` 가 마지막에 만든 몸의 값을 읽었음). `outline_push` 단위는 m (뷰 공간 거리, 0.01 — c7-fix F1, 외부 모델 json 과 같은 값). 1인칭 팔 (조각 몸 `_look_pieces`) 은 `rim_tint` 거짓 = 림 틴트 없이 (c7-fix F7). 갈고리 코트 겉은 안을 보게 감긴 겹이라 양면 셰이더가 보이는 쪽을 면 법선으로 가르고 꼭짓점 법선을 눈 쪽으로 돌림 (c7-fix F4 — 안 그러면 그림자 줄무늬). 설명 EXTERNAL.md 28절, 테스트 `test_c7_baked_matches_ext_rim`.
