## 현황
- 닌자만 전 동작 클립 15개 (idle·walk·run·jump·fall·land·평타 1~4·공중 평타 2·대시·표창·공중 표창), 서버 단계 (준비·타격·회복 u) 를 클립 눈금 0.30/0.40/0.80초에 구간별로 맞춰 타격 순간이 판정과 일치 (W23, `ext_clips.gd`).
- 탱크·사냥꾼·갈고리는 이동 클립 6개 (idle·walk·run·jump·fall·land, `clips_loco.py`·`clips_tank/hunter/hook.py`, W33) 뿐 → **평타·스킬·필살기는 코드 자세** (인형 같음). 맞음·경직·낙사·일어남·도발·승리는 4명 모두 코드+래그돌.
- W33 점수 (포즈·실루엣 1~5): 평타 탱크 3 / 사냥꾼 3 / 갈고리 3 / 닌자 4, 스킬 3 / 3 / 3 / 4.
- W34: 접지 발 IK·박자 ×1.6, 대시 손목, 사냥꾼 1인칭 소총, 탱크 1인칭 방패 축소. 1인칭 팔 모션은 여전히 코드 관절 베낌 (viewmodel).

## 할 일 (먼저 현재 상태 contact sheet → 클립 제작 → 전후, 품질 모자라면 보류)
1. **탱크 클립**: 평타 (해머 휘두름 — 큰 윈드업·무거운 타격·여운), 방패 올려치기·내려치기·어깨 박치기·땅 가르기 (R 솟는 땅 준비), 방패 막기. 서버 단계 (`moves` 의 windup/strike/recover) 에 맞춘 구간 매핑 (닌자 방식 `ext_clips.gd` `moves` 표).
2. **사냥꾼 클립**: 소총 쏘기 (조준 → 탕 → 반동 → 장전 느낌), 칼/개머리 베기 3종, 표식 조준, 추적 도약, 처형 사격 (R).
3. **갈고리 클립**: 평타 (주먹·갈고리 휘두르기), 갈고리 던지기·끌어당기기·내려찍기 준비/타격, 코트 자락 흔들림 보조 (닌자 목도리처럼 `ext_cloth` 로 코트 자락 뼈가 있으면 — 없으면 보류).
4. **맞음·경직·도발·승리·KO**: 4명 공통 코드+래그돌로 두되, **맞음 반응** (약·중·강·치명 단계별 짧은 몸 움찔: 척추·머리 회전 가산, 코드 래그돌과 겹치지 않게 모터 약할 때 클립 빠짐 규칙 유지) 과 **도발·승리 포즈** 를 캐릭터별 짧은 클립으로 (판 중 도발 이모트·결과 화면 승자 포즈, 대기실 새 모델은 W35 이후 도발 끔이라 건드리지 말 것).
5. **품질 올리기 공통**: 클립 간 크로스페이드 (`EXT_CLIP_FADE_S`) 와 윈드업 예고 가독성 (타격 직전 포즈가 읽히게), 무기/방패 손 위치 일관성, 코드 몸과 팔 길이가 달라 보이는 타격 끝이 짧은 것 (W34 측정: 서버 최대 앞면이 보이는 끝보다 0.45~1.4m 멈) 을 **클립에서 타격 순간 몸을 앞으로 내딛고 팔을 최대로 뻗기** 로 줄이기 (서버 이동·히트박스는 안 바꿈 — 시각만, 측정은 `tools/hit_reach.gd` 로 전후 비교).
6. **1인칭 팔 모션**: viewmodel 이 코드 관절을 베끼는 구조라 클립은 3인칭 몸에만 먹음 — 1인칭에서 평타·쏘기·방패 휘두름 때 팔의 윈드업·여운이 3인칭 클립과 느낌이 맞도록 `viewmodel.gd` 의 팔 모션 (가산 보정만, 구조 변경 없이) 이 가능하면 같은 곡선 (`ext_clips.gd` 의 타이밍 표) 을 재사용. 안 되면 보류.
7. 새 클립이 `moves` 단계와 어긋나면 안 됨: 각 클립 길이·구간을 테스트로 고정 (`test_ext_clips.gd` 의 단계→클립 눈금 검사 확장). Mixamo 가 필요하다고 판단되는 동작은 요청 목록 (`docs/model-review-2026-11.md` 7절) 갱신.
