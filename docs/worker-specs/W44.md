## 할 일
1. **모션 QA 도구 (핵심)**: `godot/client/tools/motion_qa.gd` (+ 필요하면 `core/replay.gd` 연동) — 재연 (`--replay <녹화>`, 렌더 끈 헤드리스 가능) 을 돌리며 **판 중 매 프레임**, 새 모델 몸마다 다음을 샘플해 CSV·JSON 요약 (`motion_qa.json`) 으로 남김:
   - **뼈 회전 불연속 (튐)**: 뼈별 이전 프레임 대비 각도 변화 (각속도) — 프레임당 임계 (예: 몸통·팔다리 > 35°/프레임, 손·발·머리 > 60°/프레임, 래그돌 구간 제외) 를 넘는 순간을 '팝' 으로 기록 (캐릭터·뼈·시각·직전 상태: 걷기/공격/맞음/일어나기/클립 전환/상태 전환 프레임).
   - **떨림 (jitter)**: 정지·서기 중 뼈 각도의 고주파 진동 (짧은 창 분산, 서버 스냅샷 보간 지터 제외) — 시선 추적·숨쉬기·천·무기 용수철 가산이 서 있을 때 떠는지.
   - **발 미끄러짐**: 접지 발의 월드 위치 이동량 ÷ 몸 이동 (방향 이동 앞·뒤·옆 포함 — W43 방향 블렌드 후 처음 측정), 접지 중인 발이 바닥 아래로 박히거나 뜨는 높이 오차.
   - **뚫림·늘어남**: 천 (망토·코트·목도리) 사슬 끝점이 몸 (몸통·다리 캡슐 근사) 안으로 들어가는 프레임 수, 스킨 삼각형 최대 신축 비 (뼈 정점의 월드 변환 후 인접 정점 거리 변화 — 갈라짐·늘어짐 검출), 무기 (해머·소총·갈고리) 가 몸 안으로 들어가는 정도.
   - **전환 이음새**: 클립 A→B 전환 프레임 전후 뼈 각도 차 (크로스페이드 내 최대 각속도), 상태 전환 (공격 끝→서기, 경직→일어나기, 낙하→착지, 대시 끝) 별 통계.
   - **관절 한계**: 팔꿈치·무릎 반대 굽힘, 목 비틀림 > 한계, 척추 누적 회전 합 한계를 넘는 프레임.
   - 소프트웨어 렌더 환경에서 **스크립트 CPU 로 돌릴 수 있어야** 함 (렌더 없이 Skeleton3D 의 뼈 포즈·월드 변환만 읽음, 느린 프레임 시간과 무관하게 같은 시뮬 시간 (고정 틱 재연) 으로).
2. **QA 실행**: 기존·새 녹화 (`new8.rec`·`N8.rec`·`rec_chars`·`rec_loop` 로 4명 각각 + 연습 방 스킬 연속 `autopilot` 녹화) 를 돌려 **캐릭터별·결함 종류별 표 + 상위 20개 팝/미끄러짐/뚫림 목록** (프레임·상태·뼈) 을 `docs/w44/README.md` 에 정리. 같은 도구를 `--no-w43` 상태로 한 번 더 돌려 W43 가산이 만든 새 결함과 없앤 결함을 구분.
3. **고치기 (영향 큰 것부터, 최대 8개)**: 예상 후보 (표가 정함) — 방향 블렌드 앞/뒤 경계 (약 90°) 에서 다리 순간 회전 (히스테리시스·크로스페이드), 일어나기 가산 시작/끝 튐, 시선 추적이 상태 전환 때 튐 (가중치 램프), 무기 용수철이 공격 시작/끝에 튐, 천 사슬이 몸을 뚫음 (충돌 캡슐 보강·쉬는 자세 당김 강화), 클립 전환 크로스페이드 부족 (종류별 페이드 추가), 걷기↔달리기 속도 문턱 진동 (히스테리시스), 뒤로 걷기 발 미끄러짐 (보폭/박자 매핑 보정), 닌자 콤보 연결 튐, 1인칭 팔 클립 구동이 상태 전환에 튐. 각 고침은 **전후 QA 수치** 로 증명 (팝 수·최악 각속도·미끄러짐 비·뚫림 프레임 수).
4. **회귀 테스트로 고정**: `tests/test_motion_qa.gd` — 합성 뼈 열 (알려진 팝·떨림·미끄러짐) 로 검출기 자체를 검증, 그리고 짧은 재연 (4명) 에서 '팝 수 ≤ 상한' 같은 느슨한 회귀 기준 (수치는 현재 상태에서 정한 상한, 고정 시드·고정 틱, flaky 하지 않게) — 앞으로 모션 변경이 결함을 늘리면 실패.
5. **재혁 PC 용**: 클라에 `--motion-qa` 인자 (또는 F3 옵션) 로 같은 검출을 실시간 (가볍게, 팝 카운터만) 켜고, 한 판 끝에 `user://motion_qa.txt` 에 '팝 상위 5개 (캐릭터·뼈·상태·시각)' 를 남겨 재혁이 '어색했다' 고 느낀 순간을 데이터로 잡게 (꺼져 있으면 비용 0, `hitch` 로거와 같은 형식).
