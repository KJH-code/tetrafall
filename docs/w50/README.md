# W50 — 안정성 점검 (v0.1.11~v0.1.19 최적화·모션 변경 감사 + 스트레스·장시간 시험)

새 기능이 아니라 안정성. 소프트웨어 렌더 (xvfb · llvmpipe) 에서만 돌린 결과라 GPU·Windows·실제 웹 브라우저 GPU 경로는 못 봄 (맨 아래 한계).
시험 도구: `godot/client/tools/soak.gd` (시나리오 6종 + idle) · `tools/soak.mjs` (서버 + xvfb 고도 + 표) · `tools/web_soak.cjs` (웹). 회귀 테스트 `tests/test_w50.gd`.

## 남은 것

- A5 (적응형 해상도 실구동) · A10 (자원 느린 증가) · A11·A12 는 미확인 — 재혁 PC (GPU) 에서 `tools/soak.mjs` 를 같은 시나리오로 돌려 비교하면 됨.
- 장시간 (1시간+) 한 판 연속은 안 돌림.

## 소프트웨어 렌더 한계

llvmpipe 라서 GPU 시간·셰이더 컴파일 비용·영상 메모리 (Vulkan 쪽 ×2) 는 믿을 수 없음. 적응형 해상도는 소프트웨어에서 꺼져 있어 못 봄. 프레임 최악값 (fmax) 은 CPU 래스터 + 같은 기계의 다른 작업 영향이 큼 (처음 방 입장 5~9초 포함) — 추세 비교에만 씀. Windows 전용 경로 (`reg` 하이브리드 찾기, 최소화·포커스 잃기) 는 못 봄.
