### 고친 것
1. **지형 네 단계** (`Scenery.build_begin`/`build_step`, `world.gd` 가 단계마다 입장문 한 칸): ① 섬 모양·뿌리 바위·먼 섬·구름 꼭짓점 ② 섬·바위 메시 ③ 빛나는 소품·구름 메시·구름 바다 ④ 먼 배경·빛 가루. 같은 난수 (`rand`) 를 이어 써서 **한 번에 지은 것과 같은 메시** (테스트: 테마 7개 모두 자식 메시 정점 수·빛 가루·먼 섬 수 일치). 짓는 중에 맵이 또 바뀌면 처음부터.
2. **맵 적용 세 단계** (`World.apply_theme_step`): ① 지형·바닥·칸 색·튀어나온 조각 ② 위험 액체 ③ 테트리미노 칸 모양·재질. `apply_theme` 는 세 단계를 몰아서 (테스트·문 끔).
3. **초상·큰 캐릭터**: 자세 굳히기 (`prime_idle` 50번) 를 몸 만들기와 **다른 프레임** 한 조각으로, 초상은 최대 3장 겹쳐 (`MAX_INFLIGHT`), **방 입장 첫 바퀴 (지형·맵·무대·칸) 가 끝날 때까지 미룸** (`Gate.entered`, 최대 90프레임) — 카드는 전환 띠 뒤라 늦게 와도 안 보임.
4. **외부 몸 붙이기 네 조각** (`External.attach_job`/`AttachJob`, `Ext.setup_a~d`): ① 장면 인스턴스·크기·쉬는 자세 맞춤 ② 재질·텍스처·LOD 표면·그림자 쌍둥이 ③ 안쪽 몸 숨기기·띠·소품 ④ 클립 재생기·천·모션 층 연결·처음 자세. 프레임당 `BODY_JOBS_PER_FRAME` 2 몸·새 몸 `BODY_BUILDS_PER_FRAME_SPLIT` 1. **다 붙기 전엔 몸을 숨기고 pose 를 안 부름** (쉬는 자세 맞춤이 관절의 처음 자세를 읽음 → T 포즈 노출 없음, 테스트 `test_bodies_hide_until_attached`). 알베도·마스크 스레드 읽기가 안 끝났으면 ① 앞에서 기다림 (최대 45프레임) — 동기 읽기 5~7ms 제거.

## 2. 몸 압박 단계 (적응형 해상도 다음 수단)

`world/adapt_calc.gd` `Ctl.press` (0·1·2): 해상도 바닥 (0.6) → MSAA 한 단계 (`cut_windows` 9창) 에서도 GPU 병목으로 계속 느리면 **`press_windows` (9) 창마다 한 단계**. 판이 끝나면 (`restart`) 전부 되돌림, 해상도가 아직 내릴 여지가 있거나 CPU 병목이면 단계 안 오름 (연속이 끊김).
- **1단계**: 먼 몸 외곽선을 앞당겨 뗌 (굵기 줄기 시작 8 → 5m, 껍질 뗌 16 → 10m, 시야각 70° 환산) + 먼 몸 자세 LOD 거리 당김 (10m 밖 30Hz → 6m, 18m 밖 15Hz → 10.8m). `WC.BODY_PRESS`.
- **2단계**: 먼 몸 그림자 끄는 거리 22 → 14m.
- 가까운 몸 (3m)·내 몸·1인칭·대기실·초상은 어느 단계에서도 그대로 (테스트).
- 확인 (`--adapt --adapt-fake-gpu 200`, 새 모델 8명 재연 30초, 프레임 1801): 3D 배율 100→85 (프레임 79) → 70 (119) → 60 (159) → **MSAA 낮춤 (359) → 몸 압박 1단계 (559) → 2단계 (759)**, 끝 `3D scale 0.60 · MSAA cut true · 몸 압박 2`. 끄는 인자 `--no-body-pressure` 면 MSAA 까지만. F3·설정 창 글에 `· 몸 압박 N`.
- 순수 계산 테스트: 단계 순서·한 번에 한 단계·`press_max`·끊김·CPU 병목이면 안 함·0 단계 표 = 원래 표·가까운 몸 불변 (`tests/test_w45.gd`).
- **안 한 것 (이유)**: 살아 있는 몸의 **메시 LOD 한 단계 교체** (5000→4000→3000). LOD 마다 알베도·마스크 UV 가 달라 재질까지 갈아야 하고, 그림자 쌍둥이·외곽선 수집 (`_ol`/`_sh` 가 처음 부를 때 한 번 모음)·천/클립 상태 (W46 소유) 와 얽혀 몸 팝 위험이 큼. 이득도 작음 (먼 몸 한 명당 −2천 삼각형 — 1단계에서 먼 몸 외곽선이 이미 빠져 몸 8명 중 먼 몸 몇 개 × 2천 = 전체의 ~3%). 하려면 `AttachJob` 으로 낮은 LOD 몸을 숨은 채 붙인 뒤 바꿔치기 (이번에 만든 조각 붙이기가 그 토대).

- 합친 메시: 몸당 그리기 3 (색 + 외곽선 껍질 + 쌍둥이 그림자 — W37 이후 최소), 삼각형 9.6k (색 4.8k × 외곽선) + 그림자 4.8k. 외곽선 거리 끄기 (W31) 는 코드 몸도 (`_ol` 전부) 적용 — 16m 밖 껍질 없음.
- **남은 큰 것 = 합치지 않은 조각의 그리기 63개 (전체 그리기의 46%, 삼각형은 5%)**: `--budget-split` 으로 조각별로 보니 몸당 3~7개 — 토르소 32삼각형·어깨 90삼각형·허리 조각·목 `neck__m*_ns` 200~400삼각형 (그림자 없음) 등이 상태 색 (피격·분노) 때문에 묶음에 못 들어가 **조각 하나당 그리기 2~3 (색 + 외곽선 + 그림자)**. 줄이는 길은 '작은 조각의 외곽선 끄기' 뿐인데 토르소 재질은 상태마다 `torso_mats` 로 바뀌어 (피격 번쩍) 복제 재질이 덮어쓰이고, 눈으로 보지 못해 (재혁 확인 없이) 모습이 바뀌는지 알 수 없어 **안 건드림**. 후보로만: 1단계 몸 압박에 '작은 조각 외곽선 끄기' 추가 (GPU 병목 때만, 몸당 ~3 그리기).
- **잔상/압사 복제 경로** (W42 풀 `snapshot_fill`): 풀 열쇠는 `char_id|c(코드)/x(외부)` 라 **코드 몸 4명도 이미 풀을 씀** (`test_snapshot_fill_matches_fresh` 가 바드·건축가 포함, `body_fx._prewarm_pool` 이 사람 몸 종류마다 2개 미리 만듦). 압사는 몸 복제가 아니라 살아 있는 몸 납작 (`scale`) 이라 복제 없음. 비용 (`tools/ghost_pool.gd --n 100`, 복제 → 풀): 닌자 2.34→0.15 · 탱크 1.75→0.16 · 사냥꾼 1.73→0.16 · 갈고리 1.73→0.18 · **바드 1.00→0.11 · 건축가 0.51→0.05 · 대포수 0.59→0.06 · 광전사 0.99→0.10 ms**.
- 몸당 재질 수: 묶음 1 (+ 외곽선 껍질 재질 1, 몸 안에서 공유) + 합치지 않은 조각 3~7 (조각마다 따로) — 위 63 그리기의 원인.
- 결론: **이번엔 줄인 게 없음** (안전한 큰 항목이 없음, 위 후보는 보류). 풀 범위·측정만 확정.

## 7. 남은 문제·소프트웨어 렌더 한계

- **재혁 PC 의 `hitches.txt` 판 요약과 F3 가 여전히 필요**: 입장 첫 바퀴 최악 프레임이 25ms 를 못 넘는지는 실제 CPU·GPU 로 다시 봐야 함 (이 환경은 프레임 바탕 비용이 지시서 가정보다 큼). 조각 크기·상한 (`CAP_MS` 12, `BODY_BUILDS_PER_FRAME_SPLIT` 1, `BODY_JOBS_PER_FRAME` 2, `MAX_INFLIGHT` 3) 은 `world_config.gd`·`entry_gate.gd`·`portrait.gd` 한 줄씩.
