## 배경
재혁 결정: 모델은 B 방식 — **제가(Claude) Blender 를 스크립트로 직접 돌려 우리 8명을 우리 규격으로 제작**한다 (재혁의 다른 세션이 Blender 5.2 로 치비 캐릭터 'Mori' 를 리깅·애니메이션·GLB 내보내기까지 해낸 결과를 보여 줬고 퀄리티가 좋았다: 둥글고 부드러운 형태, 눈·볼터치 텍스처, 25본 리그, GLB). 우리 게임은 '밀치기형 대전 (Fall Guys 식)' 3D 게임이고 캐릭터 8명 (tank 탱크·ninja 닌자·hunter 사냥꾼·bard 바드·berserker 광전사·cannon 대포수·builder 건축가·hook 갈고리) 이 한 화면에 최대 8명 나온다. 화풍은 재혁이 아직 안 골랐으므로 기본은 ③ **중간: 둥글고 굵은 형태 + 단순한 색 (텍스처 최소·꼭짓점 색 위주), 지금 게임의 두꺼운 외곽선 툰 셰이더에 잘 어울리게**. 결과를 재혁이 보고 ① 부드러운 치비 / ② 각진 저폴리 방향으로 조정한다.

1. **스크립트 파이프라인** `tools/blender/`: (a) 공통 도구 — 둥근 상자·캡슐·구에 베벨·서브디비전으로 부드러운 형태를 만드는 함수, 꼭짓점 색 칠하기 (재질을 색 영역별로 분리하거나 꼭짓점 색 속성 `COLOR_0` — 고도 쪽 툰 셰이더가 읽는 방식은 EXTERNAL.md 의 재질 처리 (원래 알베도 색 살림 + 툰·외곽선 덮기) 확인해서 맞추기), 자동 가중치 스킨, 포즈 렌더 미리보기 (정면·3/4·뒷면·몇 가지 포즈 PNG), glb 내보내기 (`export_apply` 등 Blender 4.5 옵션, 애니메이션 없이 리그 + 메시 + 재질/꼭짓점 색); (b) `tank.py`.
