## 현황 (v0.1.16)
- 4명 (탱크·닌자·사냥꾼·갈고리): 이동 6 + 공격·스킬 클립 + 맞음 움찔(방향별) + 도발·승리 + 천 뼈 verlet + 시선 ±35° + 착지·숨쉬기 + 타격 끝 개선. 닌자는 W33 이후 클립이 **처음으로 게임 길에서 제대로 먹음** (재혁 평가 아직 없음). 보류: 1인칭 팔 클립 구동 (어색해 `VM_CLIP_ARM`=0), 무기 무게 처짐, 탱크 목도리 꼬리·허리 앞 천 (모델에 없음), 갈고리 치맛자락 끝 들쭉날쭉, 사냥꾼 망토 가장자리 너덜거림.

## 할 일 (먼저 현재 상태 contact sheet → 제작 → 전후, 품질 모자라면 보류+이유)
1. **방향 이동 (스트레이프·후진)**: 지금은 이동 클립이 '앞으로 걷기/달리기' 하나라 옆·뒤로 움직일 때도 같은 앞걷기가 재생될 가능성. 먼저 확인 (몸이 이동 방향으로 도는지 / 카메라 방향을 보며 움직이는지 — 고도 `figure_motion`·`bodies.gd` 의 몸 yaw 규칙, 1인칭·3인칭 시점별). 몸이 카메라(조준) 방향을 보고 옆/뒤로 움직이면 **걷기·달리기 클립을 이동 방향에 따라 섞기** (앞·뒤·좌·우 4방향 가중 블렌드: 후진은 같은 클립을 뒤로 재생 + 상체 약간 뒤로, 옆은 다리 교차 보폭 — Blender 로 `walk_l/r`·`run_l/r`·`walk_b`·`run_b` 짧은 클립 추가하거나 기존 클립 트랙에 방향 가산). 4명 모두, 서버 이동 속도 불변. 접지 발 IK (W34) 와 호환.
2. **이동 기울임·방향 전환**: 가속할 때 몸이 앞으로 (속도에 비례 0~8°), 급정지에 뒤로 젖힘, 방향을 급히 바꿀 때 상체 비틀림 + 반대쪽 팔 반동 (코드 가산, `ext_motion.gd`), 달릴 때 팔 흔들림 폭 속도 비례. 과하지 않게, 판정 불변.
3. **일어나기 클립 (래그돌 → 서기)**: 맞아 쓰러졌다 일어날 때 (`RAGDOLL_SLUMP`·모터 복귀) 몸이 갑자기 서는 느낌 — 4명 새 모델용 **일어나기 전환** (엎드림/누움 상태에서 손 짚고 일어나기, 0.5~0.8초) 을 클립 또는 코드 가산으로: 모터가 돌아오는 구간에 `getup` 클립을 섞음 (래그돌 모터 < 0.9 면 클립 빠짐 규칙과 충돌하지 않게: 모터가 돌아올 때 getup 가중치↑). 낙사 부활 후 서기·판 시작 서기 시 첫 자세도 부드럽게 (T/A 포즈 한 프레임 방지는 이미 W27 이 방어).
4. **무기 무게·흔들림 (W38/W40 보류)**: 탱크 해머·방패 (걸을 때 아래로 처짐 + 걸음에 맞춘 흔들림), 사냥꾼 소총 (어깨끈에 걸린 듯 흔들림, 달리면 위아래), 갈고리 갈고리 팔 (걸음 반동), 닌자 칼 (등 칼 흔들림 — 칼이 몸 메시에 붙어 있으면 약한 척추 가산). 무기 뼈/손 뼈 가산 회전, 가벼운 verlet 지연 (`ext_cloth.gd` 의 짧은 사슬 재사용).
5. **닌자 클립 다듬기** (W33 이후 처음 활성화됨 — 눈으로 품질 점검): 15개 클립 contact sheet 를 다시 보고 (평타 1~4 연결 콤보, 공중 평타, 대시 잔상과의 맞음, 표창 던지기 손 위치, 서기→달리기 전환 자세 튐) 결함 목록 → 고침. 닌자 목도리 verlet 이 새 가산 (기울임·방향 전환) 과 맞는지.
6. **탱크 목도리 꼬리·허리 앞 천**: 모델 (Tripo 자동 리깅 탱크) 에 해당 메시가 없음 (마스크 칸은 목 둘레뿐) → 보류 유지, 대신 **어깨 장갑·벨트 장식의 작은 흔들림** (이미 뼈에 매인 판 조각이 있으면 가산 지연) 이 가능한지만 검토.
7. **1인칭 팔 모션**: W40 시험 (3인칭 클립 팔 뼈 차이를 1인칭 팔에 가산) 이 소총·갈고리 쥔 팔이 솟아 보류됐음. 원인 분석 (쌍둥이 몸 팔 뼈 기준 자세 차이·viewmodel 이 몸을 카메라 앞으로 옮기는 변환) 해 **쥐는 손·무기 방향을 고정하고 어깨/팔꿈치 회전만 섞기** 같은 안전한 방식 (캐릭터별 가중치 0~0.3) 을 다시 시험. 안 되면 보류 유지 + 이유.
