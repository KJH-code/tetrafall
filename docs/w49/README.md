# W49 — 모션 설정 창 (런타임 A/B) + NaN 근원 추적 (2026-11-14)

재혁이 모션을 비교하려면 클라를 인자 (`--old-gait`·`--no-w43`) 로 다시 켜야 하던 번거로움을 없앴다: **설정 창 '모션' 탭**에서 프리셋·개별 토글을 고르면 판 중에도 **다음 프레임부터** 바뀐다 (몸을 다시 만들지 않음). 서버 판정·`moves` 시간·`figure_motion` 규칙은 안 건드림 (`node tools/game-hash.js` = `bf2e2951…4cc34` 그대로).
수치는 모두 소프트웨어 렌더 (xvfb + llvmpipe, 렌더 끈 뼈 표본) — 움직임의 맛은 재혁 PC 에서 `옛 모션` ↔ `새 모션` 을 F6 으로 바꿔 가며 눈으로 봐야 한다.

- 이름: 새 모션 (기본) / 옛 모션 (v0.1.17 이전) / 최소 (코드 자세만). 개별 토글을 만지면 '직접 고름'.

- 실행 인자 (설정과 **합집합, 인자가 우선** — 인자가 끈 것은 설정 창에 주황 글로 안내): `--motion old|min`, `--no-w43` (= dir·lean·getup·weapon), `--old-gait` (= gait_new), `--no-<플래그, 밑줄은 ->` (`--no-gaze`·`--no-land-breath` …). 웹은 `?motion=old`·`?old-gait=1` 처럼 같은 `Opts.args()` 길.

## 4. NaN·영 스케일 근원

- 도구: `tools/nan_hunt.gd` (`--nan-hunt <폴더>`, 재연·판 중. `Motion_.probe` 훅이 `Ext.sync` 단계마다 뼈 지역 자세·부모 사슬 전역 basis·코드 몸 관절을 훑어 몸마다 첫 깨짐의 프레임·뼈·직전 멀쩡한 단계·몸 상태를 `nan_hunt.json` 에), `tools/nan_fuzz.gd` (상태·맞음 값·몸 크기·프레임 간격을 NaN·inf·0·±1e9 로 깨 봄).
- **재연에서는 못 다시 만들었다**: new8 (30초·40초 기본 워밍업)·lava8·game8 60초·판 중 8명 한 판 (스캔 약 130만 번) — 깨진 뼈 0, `_add_rot` 거절 0. W47 때의 정확한 트리거는 모름.
- **입력 쪽 퍼저가 찾은 입구** (고치기 전 883개 조합이 깨짐): 가산 층이 깨진 값으로 회전을 셈하면 `_add_rot` 가 NaN 을 척추 뼈 회전에 씀 → 그 자식 뼈의 `_add_rot` 은 '부모 전역 basis NaN' 이라 경고 (W47 은 이 경고만 막음; NaN 뼈는 `_reset_extra` 가 다음 프레임에 되돌려 눈에 안 띔). 깨지는 입력: ① `hit.age` 가 −10.6초보다 작음 (`exp(−age/0.015)` INF → NaN; 시계 바탕이 바뀌면 — 재연 가상 시계·반복 재생 — 맞은 시각이 옛 시계 값이라 음수, `_hit_for` 는 2초 넘는 것만 버림) ② `hit.dx/dy/pow`·`st.t` 의 NaN·inf ③ 몸 월드 크기 0·NaN (천 `step`·무기 월드 가속도의 `affine_inverse`·`orthonormalized` 경고). ①이 재혁이 본 증상 (움찔 → 부모 NaN 경고) 과 맞는 유일한 '유한한 입력으로 닿는' 경로라 가장 유력한 가설이지만 **실측으로 확정은 못 함**.
- 고침 (입구에서, W47 가드는 남김): `_hit_flinch` 는 age 가 유한하지 않거나 −0.05초 아래면 움찔 없음 · `hit_react` 가 깨진 값을 0 으로 (`Motion_.fin`) · `_add_rot` 는 더할 회전이 단위 사원수가 아니면 안 쓰고 이미 깨진 뼈는 쉬는 회전에서 다시 · 숨쉬기 `t` 는 `fin` · `_extra_layer`·`Cloth.step` 은 몸 월드 변환·부모 basis 가 `basis_ok` 가 아니면 그 프레임 건너뜀. 퍼저 결과 883 → 0, 새 테스트 4개.
