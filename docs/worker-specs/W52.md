- 서버 규칙·`moves` 시간·figure_motion(서버 설계값) 은 안 건드림. 서버 쪽 값이 원인이면 고치지 말고 보고에 적기. `node tools/game-hash.js` 가 bf2e295158bcb4165fd79b097a1784c61b33716de4e28fa3023b46284dc4cc34 와 같아야 함.
- 릴리스·마커 커밋·PR·force push 금지. 커밋 작성자 KJH-code (전역 설정 그대로), 항목마다 커밋+push (브랜치 w/W52).
- 새 문서·코드에 이메일·실명·C:\Users 경로 쓰지 말 것.
- 걸음 박자는 v0.1.19 에서 일부러 늦췄고 사용자 평가 대기 중이니 다시 건드리지 말 것 (`--old-gait` 유지). 설정 창 모션 탭의 플래그(EXT_MOTION_FLAGS)·F6 새/옛 전환이 계속 동작해야 함. 새 가산 층을 넣으면 플래그 하나로 끌 수 있게 하고 프리셋 표에 반영.
- 검증은 motion_qa(`--motion-qa`)·조합 순회(motion_combos)·contact sheet 캡처로: 전후 팝 수·각도 표와 눈으로 본 판단을 같이 보고. 소프트웨어 렌더라 "맛"은 재혁 PC 에서 F6 으로 비교해야 하니, 그럴 지점은 미확인으로 분리.
- 새 기능은 테스트(tests/test_w52.gd, run_tests.gd FILES 에 추가).

## 할 일 (우선순위 순)
1. **닌자 대시 팔 튐** (알려진 것: 팔이 74~129° 튐): 원인(클립 전환·IK·가산 층 중 어느 것인지)을 분해해 고침 + 전후 각도 표.
2. **래그돌 복귀 팝**: 맞음·낙사 후 일어날 때 골반·관절이 튀는 구간을 재서 블렌드/모터 복귀 곡선으로 줄임 (client/ragdoll.gd·ragdoll-math 순수 계산 테스트).
3. **공격·회복 구간 다리 팝** (어깨 박치기·돌진·스핀·주먹 37건): 서버 `moves` 설계값에서 오는 것은 못 고침 — 클라 쪽 다리 IK/크로스페이드로 눈에 덜 띄게 할 수 있는지만 시도하고 팝 수 전후 표로 보고, 안 되면 근거와 함께 "서버 설계 변경 필요" 로 분리.
4. **탱크 허리 앞 천·어깨 장갑 2차 모션**: 모델에 지오메트리가 없어 못 함으로 보류 중 — Blender 로 최소한의 천/장갑 조각을 추가할 수 있는지(tools/blender/tripo 파이프라인, 뼈·삼각형 수 한도 `--budget`) 타당성만 판단해 보고 (구현은 가능하다고 확신할 때만).
