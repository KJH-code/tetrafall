- 고도판 (Release v0.1.0-godot-preview 의 tetrafall.exe), 탱크, **1인칭**에서 평타 **콤보 3타·4타** 때 방패가 이상한 위치·방향으로 돌아감.
- 기준 (JS 판): `client/viewmodel.js` 의 탱크 방패 처리 (1인칭 팔·방패 IK, 콤보 단계별 자세 `VM_*` 값, `render.js` 가 부르는 곳), 콤보 단계 값은 `shared/config.js` 의 탱크 콤보 표 (몇 타인지·밀치기·방패 치기 등), 3인칭 자세는 `client/figure.js` MOVES.

## 목표
1. xvfb 로 탱크 1인칭 콤보 1~4타를 차례로 재현해 (autopilot.gd 로 연습 방 + 허수아비, 콤보 입력 `--auto practice --char tank …` 인자는 `godot/client/core/autopilot.gd` 머리 주석, 필요하면 타이밍 인자를 추가) 각 타의 프레임 연속 스크린샷 (타마다 3~4장).
2. JS 에서 같은 콤보를 Playwright (연습 방 `{type:'practice',char:'tank'}` + 허수아비, `window.__tf`) 로 찍어 비교하고, 3·4타에서 방패의 위치·회전·크기가 JS 와 다른 값(관절 각·팔 도달점·방패 부모 노드 변환)을 숫자로 대조해 원인 확정. 3인칭 몸 자세 대조는 이미 97장면 관절각 차 0.03rad 안이었다는 기록이 있으니, 1인칭 viewmodel 쪽 (복제본의 방패 분리·콤보 단계별 목표점) 이 유력.
3. 고치고 같은 장면 전/후 스크린샷, 테스트로 고정 (콤보 단계별 방패 변환 값).
