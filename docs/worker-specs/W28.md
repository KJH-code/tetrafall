# W28 — 1인칭 팔이 이동할 때 공중에 떠 보임 (팔 위쪽이 안 이어짐)

친구 피드백 (재혁 전달, 2026-11-06, v0.1.9): "팔이 1인칭에서 이동할 때 움직이면서 팔 위쪽이 연결이 안 되니까 보여서 그냥 공중에 있어 보임".
브랜치 `w/W28` (= 작업 브랜치 c08d081). 같은 시각 W27 (대기실 T 포즈·초상) 이 `portrait.gd`·대기실 무대를 고치는 중 — 겹치지 않게 1인칭 팔 쪽만.

## 원인 (추정, 재현으로 확인)
1인칭 팔은 팔꿈치 아래만 따로 만든 **닫힌 전용 팔 메시** (`vm_node` — 닌자 `ninja_vm`·사냥꾼 `hunter_vm`·갈고리 `hook_vm`) 이거나 (탱크는 로더가 모델에서 팔꿈치 아래 삼각형만 남김, `vm_from`). 이동할 때 걷기 흔들림·viewmodel 이 허리 관절을 카메라 앞으로 옮기는 움직임·카메라 앞 FOV 때문에 **팔 윗부분(팔꿈치 위 절단면)이 화면 안으로 올라와 보이고** 어깨·몸통에 이어지지 않아 팔이 공중에 떠 있는 것처럼 보임. 판 중 1인칭 이동·점프·대시·공중에서 확인.

## 할 일
1. **재현**: `--ext` (기본 켬) 로 닌자·탱크·사냥꾼·갈고리 각각 1인칭에서 걷기·달리기·점프·대시·평타·앉기 프레임을 찍어 팔 위쪽 끝이 보이는 프레임을 찾아 보고. (`tools/move_shot.gd`·`vm_shots`·W23 `tools/`·`--view first` 로 판 화면.)
2. **고치기**: 팔이 몸통(화면 아래 가장자리 밖)에서 이어져 나오는 것처럼 — 후보 (측정해서 고를 것):
   - 닫힌 팔 메시를 **팔꿈치에서 어깨 쪽으로 길게** (위팔·소매·어깨 갑옷 일부까지, 끝은 화면 아래/옆 밖으로 나가게) 늘리고 끝을 몸통 안으로 묻기 (단면이 화면 안에 안 보이게). 탱크는 어깨 장갑까지 포함하도록 로더 팔 범위 (`vm_from`) 를 어깨까지 넓히거나 닫힌 팔을 만들어 쓰기.
   - 또는 viewmodel 이 팔을 카메라 앞으로 옮길 때 아래로 더 내려 윗면이 화면 밖에 남게 하는 위치 조정 (모든 외부 몸 공통, `VM_*` 설정), 걷기 흔들림 진폭이 큰지 확인.
   - 팔 윗단면을 화면 위로 드러내지 않는 **카메라 쪽 가림** (근평면 가까이 클립, 화면 가장자리 비네트) 은 마지막 수단.
   - 예전 코드 몸 1인칭 (바드·광전사·건축가·대포수) 은 기존 그대로 두기 (이 문제 없음).
3. 닫힌 팔 메시를 만드는 Blender 스크립트 (`tools/blender/tripo/ninja_vm.py`·`rig_hook.py` 의 `make_vm`·`rig_hunter.py`·탱크 쪽) 를 고쳐 glb 를 다시 뽑고 (`godot --headless --import` 후 `.import` 와 함께 커밋), 테스트 (1인칭 팔이 닫혀 있고 몸 쪽 끝이 viewmodel 화면 가장자리 밖에 있음 / 이동·점프·대시 프레임에서도 윗단면이 카메라 시야 안에 안 들어옴) 추가.
4. 검증: `tests/run_tests.gd` (221 기준), `tools/shader_check.gd` (xvfb gl_compatibility), 고치기 전·후 1인칭 이동·점프·대시·평타 프레임 나란히 (4명 모두). 캡처 경로 보고 (커밋 금지).
