## 할 일
1. **리깅**: 우리 관절 이름 그대로 (`tools/blender/ref/tank_rig.json`, `README.md` 규격) 뼈대 만들기. 관절 위치는 모델 렌더(앞·옆)에서 읽음 (어깨·팔꿈치·손목·골반·무릎·발목·목·허리). 쉬는 자세는 W19 규격과 같게 (팔 내림 — 모델이 A 포즈라 조정 필요하면 `tank.json` yaw·정렬로).
   스킨은 **조각(분리된 덩어리)마다 가장 가까운 뼈에 단단히** (자동 가중치는 분리 조각 때문에 안 먹음). 경계(허벅지/골반, 위팔/어깨 갑옷)는 조각 중심·부모 뼈 거리로 정하고, 필요하면 허리·관절 근처 조각만 두 뼈에 부드럽게. 망토 = 척추(몸통) 뼈, 가능하면 뒷자락만 허리 아래 뼈 보조. 투구·머리 = head. 손(주먹) = 손목 뼈.
   검증: 걷기·팔 들기(공격)·쪼그림·점프 자세를 Blender 로 렌더해서 갈라짐·뚫림 확인(앞·뒤·옆), 문제 곳 고치기. 결과 렌더 시트를 PR 설명이 아니라 `docs/` 아래가 아닌 **커밋 안 하고** 최종 보고에 파일 경로로 알림 (이미지 커밋 금지는 아니지만 용량 주의).
2. **소품 분리**: `cellB_60k.glb` 에서 방패(별 문양)와 해머를 잘라 각각 `tank_shield.glb`(W19 규격 그대로 — 손 관절에 붙는 `keep`/`attach` 방식은 `chars/EXTERNAL.md` 8절, 기존 tank.json 의 shield 항목 참고)와 `tank_hammer.glb` 로. 위치·크기는 몸 모델 손 크기에 맞춤. 방패 손잡이 자리·잡는 방향이 1인칭 콤보 (평타 3·4타) 에서 손에 붙어 보이는지 확인 (viewmodel shield-hold `VM_SHIELD_*`).
3. **게임에**: `godot/client/assets/models/ext/tank.glb` + `tank.json` (height·yaw·offset·tint·label_lift·vm_from·vm_snap·lods 는 W19 값 출발점) 갱신, 텍스처는 구운 알베도 그대로 (몸 색 `tint:"band"` 허리 고리 또는 어깨 장식 일부만 — 모델 자체가 갈색·빨강이라 `keep` 이면 팀 구분이 안 되니 band 를 어깨/망토 중 눈에 띄게 하는 방법을 골라 제안·시도).
