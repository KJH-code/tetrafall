재혁 (2026-11-09): 지금은 애니메이션·모델을 새로 못 받음 → "나머지부터". 이 워커는 **받은 에셋 그대로 코드·셰이더·Blender 스크립트로 고칠 수 있는 것**. 브랜치 `w/W34` (= 작업 브랜치 c893c8d, v0.1.13). 같은 시각 W35 가 UI·이펙트·월드 쪽 버그, W36 이 웹·배포 쪽을 함 — 겹치지 말고 `chars/`·`shaders/g3.gd` 의 몸 재질·`tools/blender/`·`ext/` 에셋·viewmodel 만. 서버 판정·`moves` 타이밍은 건드리지 말 것.

## 할 일 (각 항목 먼저 현재 상태를 캡처로 재현 → 고침 → 전후 캡처)
1. **팀 색 칸 경계 (텍스처 마스크)**: 지금 `tint:"mask"` 는 꼭짓점 단위 판정이라 판 LOD 에서 경계 삼각형이 어긋남 (닌자 48~55%, 탱크 32~54%, 사냥꾼 16~36%, 갈고리 5~15%: `docs/model-review-2026-11.md`). `tools/blender/tripo/relod.py` 가 LOD 마다 알베도를 굽고 마스크도 굽도록 확장 (마스크 텍스처 = 같은 UV 에 R 채널 면적 마스크, 1024), `shaders/g3.gd` 의 mask 경로가 정점 UV2 대신 이 마스크 텍스처를 읽게 (경계가 텍셀 단위로 부드럽게). 기존 stage 모델 (원본 UV, 이미 UV2 마스크) 은 같은 방식으로 호환. 4명 대기실·판 LOD 3단계에서 어긋난 연회색/어두운 칸이 사라지는지 전후 캡처, 마스크 면적 테스트 (칸 ≥ 5%, 경계 삼각형 비율 감소), `tools/shader_check.gd` 0 에러, 판 중 드로우콜 안 늘게 (재질 변형 늘림 주의: W30 prewarm 목록에 새 변형 포함).
2. **발 미끄러짐 줄이기** (W33 측정: 접지 발이 뒤로 가는 거리 ÷ 몸 이동 거리 닌자 0.24~0.37, 탱크 0.26~0.28, 사냥꾼 0.39, 갈고리 0.30~0.33; 이상은 0 근처): `tools/foot_slide.gd` 로 현재 수치 재측정 → (a) 이동 클립 재생 속도·보폭을 실제 이동 속도 (서버 `speed`) 에 비례 (`ext_clips.gd` 의 속도 매핑), (b) 접지 발 고정 (간단 2본 IK: 허벅지-정강이-발, 접지 단계에서 발 월드 위치 유지, `Ext.sync` 뒤 후처리, 클립이 도는 몸 한정, 먼 몸은 건너뜀), 둘 중 효과 큰 것. 수치 전후 표.
3. **공중 대시 자세에서 무기가 머리 위로 곧게 솟음** (4명 공통, `figure_pose` 공용): 외부 몸일 때 무기 (해머·소총) 가 손 관절을 따라 비정상 각이 되는지 원인 (손 뼈 회전 제한/맞춤 회전 A) 확인 → 외부 몸 쪽에서 손목 회전을 현실 범위로 클램프하거나 attach 각 보정 (`attach` 의 rot). 코드 몸은 그대로.
4. **사냥꾼 1인칭 소총**: 지금 두 주먹만 보임 (모델 소총은 1인칭 팔에 안 들어가고 코드 총은 숨김). 소총 조각을 `hunter_vm` 에 포함 (닫힌 소총 메시, 조준선이 화면 가운데를 가리지 않는 위치: 오른쪽 아래, 크기 viewmodel 비율) 하거나 `attach vm:true` 로 쌍둥이 손에 붙임 — 조준·사격 시 반동이 보이게. 전후 1인칭 프레임 (서기·조준·탕·달리기).
5. **탱크 1인칭 방패**: 방패 올려치기·내려치기 때 화면 왼쪽 아래를 너무 가림 → 방패 크기·위치 (`VM_SHIELD_*`, `tank.json vm`) 를 줄이되 3/4 타 방패 쥐기가 손에 붙어 보이게 (재혁이 예전에 지적한 버그) 유지.
6. **갈고리 코트 안감 비침·오른 주먹 찢어진 조각**: 큰 팔 동작에서 보이는 찢어진 조각 (원본 코트-주먹 한 덩어리) 을 `rig_hook.py` 에서 해당 삼각형 제거/가중치 정리로, 코트 안감 비침은 면 방향·양면 렌더 설정 확인. 캡처 전후.
7. **팔 길이 차이로 서버 판정 위치 vs 보이는 타격 위치 어긋남 측정**: 서버 타격 중심 (`moves`·`game-combat` 의 히트박스 위치, 고도 쪽 C# `Game.Combat`) 과 모델 손/무기 끝 월드 위치를 평타 타격 프레임에서 수치로 (`tools/` 새 측정 스크립트) 비교해 표로 보고하고, 보정이 필요하면 `height`·`offset`·팔 스케일 제안만 (적용은 눈으로 확인한 뒤 작게).
