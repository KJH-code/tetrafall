# W41 렉 사냥 (2026-11-10)

재혁 v0.1.15 렉: (a) 켠 직후 메뉴 (b) 판 시작 직후 (c) 블록 낙하·궁 같은 이벤트. 환경 = 소프트웨어 렌더 (llvmpipe, 480x270, 4코어) — **스크립트 CPU ms 는 믿을 수 있고, 실제 GPU 셰이더 컴파일·텍스처 올리기 ms 는 못 잼** (llvmpipe 의 LLVM 컴파일을 '첫 그리기 스톨' 대리 지표로만 씀).

## 도구
`--hitch --lag-log f.tsv` (프레임마다 한 줄) · `--first-use --first-out f` (구간별 처음/둘째 부름 ms) · `--boot-log` · `--menu-wait N` · `--start-delay N` · `--sched-log` · `--mat-census`. 끄기: `--no-prewarm-sched` `--no-tex-prefetch` `--no-ext-warm` `--no-lazy-tex`.

## 고친 것
1. 프레임 예산 스케줄러 `world/prewarm_sched.gd` (3ms 예산·입력 뒤 쉼·평소 상대 느린 프레임 뒤 쉼·굶음 방지·WAIT·취소).
2. 메뉴 작업을 조각으로: 파일 요청 → 받기 → 정보 → 텍스처 요청 → 몸 데우기 (stage 별 프레임), 판 빛 LUT 한 층씩, 초상 8장 250ms 간격 + 스레드 읽기 뒤 줄 세움.
3. 대기실 사람 캐릭터 텍스처 스레드 미리 읽기 (`chars/tex_prefetch.gd`) — 초상·몸 첫 만들기의 동기 읽기 제거.
4. world 숨김 때 그리기 작업을 대기실로 미룸 + G3.prewarm 재질 3개씩 조각 + 재질 미리 그리기 (`warm_scan.gd`: fx_glow·fx_smoke·bblock·sky·StandardMaterial 등) + 유령 재질·가장자리 어둠·위험 경고 캔버스 셰이더. 테스트 `WARM_TABLE` 이 셰이더 파일마다 데우는 길을 강제.
5. 적응형 해상도: 4초 유예·스파이크 제외·바꾼 직후 한 창 건너뜀 (테스트: 스파이크만으론 안 내려감, 계속 느리면 내려감).
6. 몸 만들기 프레임당 8ms 상한 (`BODY_BUILD_MS`).
7. 히치 로거: 이벤트 태그·첫 이벤트·블록 낙하 시작·미리 하기, 판 끝 상위 5개 요약 (hitches.txt 와 F3).

## 남은 문제 (보류)
- 방 입장 한 프레임 ~70~100ms: 어두운 무대 (23~41) · 지형 (16~25) 첫 만들기. 메뉴에서 미리 지으려면 판 크기·테마가 맞아야 해 위험해서 보류.
- 카운트다운 HUD 첫 빌드 22ms.
- 닌자 R/F 잔상 body_fx 매번 4~6ms (첫 사용 아님).
- 실제 GPU: 셰이더 컴파일·텍스처 업로드 ms 는 못 잼. 재혁 PC `--hitch` 의 한 판 요약 (`user://hitches.txt` `# ---- 판 요약`) 필요. 스킨 몸 유령 갈래 셰이더는 몸 데우기가 안 덮음.
- Playwright 웹 대기실 진입은 이번에 안 돌림 (웹 내보내기만 확인: pck 10.58MB).
