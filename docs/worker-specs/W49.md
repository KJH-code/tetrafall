## 할 일
1. **설정 창 '모션' 줄/절**: 설정 창 (`ui/settings.gd`, 960×540 에서 판이 안 넘치는 기존 높이 테스트 `test_ui_scale` 유지 — 한 줄을 늘려 깨지면 기존처럼 접이식/탭/가로 배치로) 에 **모션 프리셋 선택** — `새 모션 (기본)` / `옛 모션 (v0.1.17 이전)` / `최소 (코드 자세만)` — 과 개별 토글 (`걸음 박자 옛값`·`방향 이동(스트레이프) 블렌드`·`이동 기울임`·`일어나기`·`무기 처짐`·`천 시뮬`·`시선 추적`·`착지·숨쉬기`·`맞음 방향별 움찔`·`1인칭 팔 클립 구동`). 값은 `View.settings` 저장 (`tf-settings`), 기본은 모두 켜짐 (현재 동작 그대로), 판 중에도 바꾸면 **다음 프레임부터 즉시** 적용 (몸을 다시 만들지 않고 `Ext` 의 가산 층 플래그만). 기존 인자 (`--old-gait`·`--no-w43`·`--no-w44` 등) 는 계속 동작하고 설정과 합집합 (인자가 우선). 웹 (`?old-gait=1` 등) 도 설정을 읽게 (`Opts`).
2. **모션 가산 층 플래그화**: 지금 W43/W44/W46 의 가산 (방향 블렌드·기울임·일어나기·무기 용수철·시선·착지·숨쉬기·맞음 방향·1인칭 클립 팔·천 몸 충돌/회전 제한) 이 코드에 흩어져 켜짐/꺼짐이 `Opts` 인자 하나 (`--no-w43`) 에 묶여 있다면, `chars/chars_config.gd` 의 **한 표** (`EXT_MOTION_FLAGS`: 이름 → 기본값) + `chars/ext_motion.gd` 의 `flag(name)` 로 정리해 설정/인자/테스트가 같은 길을 쓰게. 꺼진 플래그는 **비용 0 으로 건너뜀** (CPU 전후 `--budget`). 프리셋은 이 표의 값 묶음 (`옛 모션` = W46 이전 걸음 + W43 이전 = 방향·기울임·일어나기·무기 처짐 꺼짐 + W44 천 수정은 유지(버그 수정이라), `최소` = 클립만 + 코드 자세).
3. **설정 변경이 안전한지**: 판 중 토글해도 팝·T 포즈·크래시가 없는지 (`motion_qa` 로 토글 전후 팝 수, 모든 조합 8~16개를 재연에서 순회하는 테스트 — 전부 켬/전부 끔/하나씩 끔), 종료 rc=0.
4. **NaN 근원 추적**: W47 통합에서 `_hit_flinch → _add_rot` 에서 **부모 뼈 전역 basis 가 NaN 이거나 영 스케일**이어서 경고가 폭주하던 것을 `basis_ok` 가드로 막았으나 **처음 어디서 NaN/영 스케일이 생기는지는 모름**. 재연 (`new8.rec`·`N8.rec`·연습 방 자동 조종) 에서 `Skeleton3D` 뼈 포즈·`Ext.sync` 단계별로 **처음 NaN/영 스케일이 나타나는 프레임·뼈·직전 단계** (클립 층·천 verlet 회전 속도 제한·시선·착지·일어나기·slerp 의 180° 분기·`Basis` 직교화 실패) 를 찾는 `tools/nan_hunt.gd` 를 만들어 원인을 확정하고 **원인 지점에서 막고** (가드는 남김), 재연 경고 0 + 새 테스트 (원인 입력을 재현하는 합성 케이스 → NaN 없음).
5. **모션 도움말 한 줄**: 설정 창 모션 절에 '어색하면 `옛 모션` 으로 바꿔 비교해 보세요' 와 현재 프리셋 이름. 판 중 단축키 (예: 키 설정 `motionToggle` 기본 F6) 로 **새↔옛 모션 즉시 전환** (재혁이 같은 순간을 눈으로 비교).
