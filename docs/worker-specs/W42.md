# W42 — 최적화 6차: 방 입장·카운트다운 한 프레임 덩어리, GPU 첫 사용 커버리지, 반복 비용

재혁 (2026-11-10): "다음 최적화". 직전 W41 (v0.1.16) 이 메뉴·판 시작 직후의 큰 덩어리를 프레임 예산 스케줄러로 쪼갰으나 **남긴 것**: ① 방 입장 한 프레임 70~100ms (어두운 무대 23~41ms + 지형 만들기 16~25ms + 맵 적용 5~15ms), ② 카운트다운 시작 때 HUD 첫 빌드 22~26ms·판 빛 LUT·지형 13~16ms, ③ 닌자 잔상 `body_fx` 가 **매번** 4~6ms, ④ 스킨 몸 유령 갈래 셰이더 미커버, ⑤ **블록 낙하·갈고리 궁·탱크 궁 때 렉의 GPU 쪽 원인 (셰이더 컴파일·텍스처 업로드) 은 못 가림** (CPU 첫 사용 값은 0 이었음). 재혁 PC 의 `hitches.txt` 판 요약은 아직 없음. 브랜치 `w/W42` (= 작업 브랜치, v0.1.16 코드 + 병합 수정 ce8fb8c). 같은 시각 W43 이 `chars/ext_clips.gd`·`ext_motion.gd`·`external.gd` 의 모션/클립·`tools/blender/tripo/` 를 만짐 — **그쪽은 건드리지 말 것**. 서버 판정·규칙 금지. 모습 불변.

## 할 일 (측정 → 고침 → 전후, 추측 금지)
1. **방 입장 한 프레임 쪼개기**: 화면 전환 슬래시 (`shared/wipe.js` 에 해당하는 고도 쪽, 메뉴→방 짧은 전환 ~400ms) **띠가 덮는 동안** 일을 나눠서 함 — 어두운 무대 (`lobby_dark`)·지형 미리 깔기 (`lobby_preview`)·맵 적용·`G3.prewarm` 일부·몸 만들기를 `PSched` (W41 프레임 예산 스케줄러) 작업으로 옮겨 프레임당 예산 안에서. 입장 직후 첫 프레임이 70~100ms → 25ms 이하 목표 (스크립트 CPU ms, 소프트웨어 렌더). 메뉴에서 방 만들기 버튼을 누른 순간부터 대기실이 완전히 보일 때까지 총 시간은 늘지 않게 (전환 띠 안에 끝나게). 링크로 바로 입장하는 경우 (`?room=`) 도 같은 길.
2. **카운트다운 시작 한 프레임**: HUD 첫 빌드 (`updatePlayers` 8명 카드·킬 점수 띠·판 중 HUD 노드 생성) 를 대기실에서 숨은 채 미리 만들고 (판 시작 시 보이기만), 판 빛 LUT·지형 칸·위험 표면을 카운트다운 전 대기실/전환 띠 동안 스케줄러로 이어 만들기. 카운트다운 시작 프레임 90~130ms → 30ms 이하 목표. 판 시작 신호가 서버에서 오는 순간부터 첫 판 프레임까지 총 시간은 늘지 않게.
3. **닌자 잔상 `body_fx` 매번 4~6ms**: 잔상 (대시·베기 잔상) 이 매번 몸 복제·재질 생성을 하는지 확인 → 풀 (미리 만든 몸 복제 N개 재사용)·재질 공유·생성 대신 보이기/숨기기로. 예전 몸 4명의 압사 납작 몸·낙사 잔상도 같은 길인지 확인.
4. **GPU 첫 사용 커버리지 검증 (핵심 — 렉의 마지막 후보)**: 소프트웨어 렌더 (llvmpipe) 는 셰이더를 처음 그릴 때 LLVM 컴파일이 오래 걸리는 것을 **첫 그리기 스톨 대리 지표**로 쓸 수 있음 (W30·W41 이 같은 방법). 8명 캐릭터 모두의 스킬·궁 (탱크 R 솟는 땅·갈고리 R 덩어리·건축가 R·대포 R·바드·광전사·닌자·사냥꾼), 블록 낙하 시작·착지, 폭탄, 아이템, KO 연출 (스매시 줄기·슬로모션·압사), 유령화·무적, 하늘 시점, 위험 표면 차오름, 번개/충격파 이펙트를 **prewarm 없이 처음 그린 프레임 렌더 ms (스톨)** vs **prewarm 있는 상태의 같은 이벤트 첫 프레임** 으로 비교해 prewarm 이 못 덮는 이벤트 목록을 만들고 (`--first-use`·`--mat-census`·`--lag-log` 확장), 못 덮는 것은 `world/warm_scan.gd` 의 목록에 추가. `WARM_TABLE` 테스트 (셰이더 파일마다 데우는 길 강제) 를 이벤트 재질·메시·파티클 (텍스처 `chunk_tex` 포함) 수준으로 넓힘. **이 항목의 결과가 '재혁 PC 에서 블록 이벤트·궁 렉이 사라지는지' 의 가장 큰 변수**.
5. **스킨 몸 유령 갈래 셰이더** (W35 반투명 깊이 패스가 스킨 갈래 재질을 처음 그릴 때 컴파일) 를 미리 켜는 길 추가 (유령화·무적 상태 전 몸 1개를 숨은 채 한 번 그림, 스케줄러).
6. **프레임당 반복 비용 재점검**: `--budget` 구성표 (새 모델 8명 3인칭·전체 보기·예전 몸 8명) 를 다시 내서 v0.1.16 후 상위 3개 (몸 CPU, 떨어지는 칸, 월드) 에서 줄일 것이 있는지 (HUD 매 프레임 갱신은 바뀔 때만, W40 천 시뮬 + 시선 비용 +0.77ms 의 먼 몸/가려진 몸 건너뛰기 강화 — `pose_lod` 거리 기준, 화면 밖 몸은 시뮬 정지).
7. **히치 로거로 마무리 확인**: 재연 (`--replay` + `--hitch` + `--lag-log`) 을 전 후로 돌려 판 요약 (원인 상위 5개·최악 ms) 이 줄었는지, 이 환경에서 못 가린 것은 보고에 명시.
