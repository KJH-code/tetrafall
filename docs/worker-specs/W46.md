## 할 일 (먼저 QA 도구 `motion_qa` 로 현재 수치 재현 → 고침 → 전후 수치)
1. **탱크 허리 장갑 스킨 수리 (Blender)**: `tools/blender/tripo/` 에 `model_audit.py` 로 늘어나는 삼각형 (허리 장갑·벨트·앞 천) 을 찾고, 가중치를 **다리 뼈 둘에 92% → 골반/허리 뼈 (Hips·Spine) 중심** 으로 재분배 (가까운 뼈 거리 + 법선 방향, 다리 뼈 영향 한계 반경, 부드러운 경계), stage + 판 LOD 3단계 (`relod.py`·`relod_merge.mjs`·`maskbake` 와 호환: LOD 가 stage 가중치를 Data Transfer 로 옮기는 단계를 다시 돌림) 에 적용, `tank.glb` 재생성. 전후: 쪼그림·달리기·대시·큰 다리 자세 contact sheet + `motion_qa` 삼각형 늘어남 최댓값 (×13.9 → ≤ ×4 목표) + `model_audit.py` (뼈 4 이하·가중치 합 1).
2. **탱크 허리 장갑·어깨 장갑의 작은 2차 모션**: 1번 이후 허리 앞 천·벨트 장식을 골반 뼈 아래 **작은 뼈 사슬** (`cloth_bones.mjs` 로 추가: 2~3개 마디) 로 만들어 verlet 시뮬 (`ext_cloth.gd`) — 달릴 때 살짝 날리고 점프에서 흔들림. 몸/다리 충돌 반지름은 QA 가 스킨 메시에서 잰 값으로. 모델에 해당 메시가 없으면 (W40 에서 '목도리 꼬리 없음' 이었던 것) 보류+이유.
3. **달리기 다리 팝 줄이기**: `motion_qa` 에서 무릎·정강이 표본당 35~63° 팝이 나오는 위상을 찾아 (클립 키프레임 간격·박자 ×1.6 때문에 한 프레임 건너뛰는 위상) 달리기 클립의 키 밀도/보간 (Blender FK 클립 `clips_loco.py` 재생성 시 키 수 늘리기·보간 곡선) 또는 `ext_clips.gd` 의 박자 배율을 **속도 비례 연속 값** 으로 (W34 의 고정 ×1.6 대신, 걷기~달리기 사이 부드러운 변화), 발 접지 IK 와 호환. 전후: 달리기 무릎 팝 수·최악 각속도, 발 미끄러짐 비 (아래 4번 새 판정으로).
4. **발 미끄러짐 판정 개선 + 고치기**: QA 의 발 접지 판정을 신뢰할 수 있게 (속도·높이 임계를 서 있을 때 0 으로 맞추고, 발 높이 **지면 근처 + 수평 속도 최소 구간** 을 디딤으로, 걸음 위상별로 디딤 구간 추적, 앞/뒤/옆 이동 따로 집계). 새 판정으로 4명 × 5방향 (앞·뒤·좌·우·대각) 미끄러짐 표를 내고 큰 것 (뒤로 걷기 발 미끄러짐 W43 후 처음) 을 보폭/박자 보정으로 고침. 접지 발 IK (`ext_motion.gd _stride_ik`) 가 방향 이동에서 올바른지.
5. **슬러프 180° 팝 (닌자 대시 팔 129°·래그돌 복귀)**: 클립 → 코드 가산 전환/래그돌 복귀에서 쿼터니언 최단 경로 선택 (`dot < 0` 이면 부호 반전) 을 `external.gd` 의 클립/코드 혼합과 래그돌 복귀 혼합에 적용, QA 로 팝 수 전후.
