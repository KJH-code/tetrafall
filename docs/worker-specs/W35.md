# W35 — 남은 화면·이펙트·월드 버그 정리

재혁 (2026-11-09): 지금은 애니메이션·모델을 못 받음 → "나머지부터". 이 워커는 **UI·이펙트·월드 쪽 알려진 버그·미완**. 브랜치 `w/W35` (= 작업 브랜치 c893c8d, v0.1.13). 같은 시각 W34 가 `chars/`·몸 재질·`tools/blender/`·viewmodel, W36 이 웹·배포를 함 — 겹치지 말고 `ui/`·`fx/`·`world/`(몸 재질 제외) 만. 서버 판정·규칙 건드리지 말 것.

## 할 일 (각각 **먼저 지금도 재현되는지** 확인 — 이미 고쳐졌으면 그렇게 보고하고 넘어감)
1. **대기실 큰 캐릭터를 눌러도 스킬 카드가 안 열림** (`stage_box` 가 클릭을 삼킴 — JS판은 큰 캐릭터나 '스킬 보기' 를 누르면 `#char-card` 가 열림): 고도 대기실 (`ui/char_stage.gd`·`ui/lobby*.gd`·`ui/char_card`) 에서 큰 캐릭터 클릭 + '스킬 보기' 둘 다 열리게, 다시 누르거나 다른 곳 누르면 닫힘, 새 모델·예전 몸 모두. UI 노드 테스트 (`test_ui_nodes`) 추가.
2. **미완 이펙트 목록** (`fx/README.md`·`docs/` 의 이펙트 미완 메모, W 이펙트 개선 때 남긴 것): (a) 사냥꾼 표식 '취약' 마크 모양 (JS `hunt-marks.js` 의 칸 수·꽉 참·붙는 순간 커짐·맞은 사람 화면 가장자리 알림과 같게 — 고도 `world/hunt_marks.gd`), (b) 탱크 R '솟는 땅' 질감, (c) 갈고리 chunk(덩어리) 재질, (d) 1인칭에서 내 발밑 링(바닥 원) 숨기기, (e) 갈고리 쇠사슬 팽팽함 빛, (f) 방어구 맞음 반응 (JS 의 아머 히트 반응). 각 항목: 현재 모습 캡처 → JS판 (`client/` 의 같은 이펙트) 기준과 비교 → 고침 → 전후. 이펙트 세기는 `fx/fx_config.gd` 한 곳, '움직임 줄이기'·화질 낮음이면 끄는 규칙 유지.
3. **반투명 몸 (유령화·무적) 삼각형 정렬 없음**: 스킨 메시 하나가 반투명일 때 안쪽 삼각형이 앞뒤로 섞여 보이는지 확인 (새 모델·예전 몸). 보이면 반투명 몸은 깊이 선(prepass)·재질 `depth_draw_mode` 조정으로 정리 — 그림자·외곽선·성능 영향 없게.
4. **판 중 HUD·결과·대기실 소소한 것**: `docs/` 와 `CLAUDE.md` 의 화면 규칙 (판 중 HUD 모양·킬 점수전 화면·결과 판이 메뉴와 겹침 버그의 재발 여부 — 승리+스탯 표와 메인 메뉴 겹침 재현 시도: 판 끝 → 결과 → '방 나가기' → 메뉴 / 판 중 나가기, 연속 판) 를 점검해 어긋난 것 목록과 고침. 해상도 1280×720·960×540·2880×1800·UI 배율 100/200% 에서 화면이 안 넘치는지 캡처.
5. **JS판과 다른 곳 (재혁 초기 지적 '타이틀·메인 메뉴 맛이 없음') 재점검**: 타이틀·메뉴·대기실 모습을 JS판 (`client/` 타이틀·메뉴, Playwright 로 띄울 수 있음) 과 나란히 캡처해 차이 표를 만들고, 눈에 띄는 차이 (빛 로고 위치·버튼 모양·배경 장면·전환) 상위 3개를 고침.
