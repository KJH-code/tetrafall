## 0. 가장 큰 발견 — 동작 클립이 팔다리에 안 먹고 있었음 (닌자 포함)

`Ext` (외부 몸) 의 `_process` 는 코드에서 `set_process(false)` 로 끄는데, 고도가 노드가 트리에 들어올 때 (`_ready`) 다시 켜서 (body.gd 의 `batch.set_process(false)` 주석과 같은 함정) **판 몸도 매 프레임 `body.pose` → `sync(st)` (코드 + 클립) 가 끝난 뒤 `Ext._process` → `sync()` (st 없음 = 코드 구동만) 가 한 번 더** 불렸음. 코드 구동 (`_code_sync`) 이 팔다리·골반 같은 '맞춘 뼈' 를 도로 덮어써서, 닌자의 손으로 만든 클립 15개는 척추·목·머리 같은 '안 맞춘 뼈' 에만 먹었음 (W23 의 확인은 `preview_clip` = 강제 클립이라 이 길을 안 지남). 재현: `tools/pose_sheet.gd` 에서 클립 팔을 극단값 (팔 90°) 으로 넣어도 그림이 안 변함 → 수정 뒤 변함 (`tests/test_ext_clips.gd` `test_process_does_not_overwrite_clip`).
**수정**: `external.gd` — `sync(st)` 가 부른 프레임을 기록하고 (`st_frame`), 같은 프레임의 `_process` 는 건너뜀 (판 몸만). 닌자는 이 한 줄로 평타·대시·표창 클립이 처음으로 게임 길에서 제 모습 (`after_ninja_atk.jpg` ↔ `before_ninja_atk.jpg`: 단검 든 손·찌르기·앞차기·공중 베기가 클립 자세).

## 5. 해보고 못 넣은 것 (보류 + 이유)

- **발 IK / 박자 맞춤**: 위 6절 수치로 보폭을 키우는 것까진 했으나 한계 — 코드 걸음 위상은 몸이 4.5 m/s 로 가는데 한 바퀴 (두 걸음) 가 1.7~2.5 m (몸 키 1.6 m) 라 클립이 현실적인 박자·보폭으로는 못 따라감. 보폭을 더 키우면 다리가 과장되고, 박자를 올리면 (클립 위상 배속) 3~4배 빨리 허우적. 진짜 해결은 발 IK (접지 시점 고정) 또는 코드 위상 속도·`FIGURE_GAIT.freq` 재설계 (코드 몸·래그돌·판정과 얽혀 W33 범위 밖).
- **사냥꾼 1인칭 소총**: 소총 조각을 stage 에서 뽑아 `hunter_rifle.glb` 로 만들고 오른손 `vm: true` attach 로 붙이는 길이 맞지만 (viewmodel 코드는 안 건드림) 손 방향·길이를 맞추려면 1인칭 화면을 여러 번 보며 조정해야 하는데 소프트웨어 렌더 한계와 시간 때문에 품질 있게 못 끝냄. 억지로 넣지 않음.
- **마스크 텍스처 굽기 (팀 색 칸 경계)**: 필요한 일 = ① `relod.py` 가 LOD 마다 마스크 (R8, 1024) 를 새 UV 로 굽기 ② stage 는 꼭짓점 마스크를 UV1 공간에 래스터 ③ `shaders/g3` 가 UV2.x 대신 마스크 텍스처 샘플. ③ 이 셰이더 (W32 가 world/·렌더 설정을 만지는 영역과 같은 파일군) 라 충돌 위험이 커서 보류. 수치 근거는 2절.
- **판정 위치 vs 보이는 타격 위치**: 모델 손 뼈 위치와 서버 타격 중심의 정량 측정 도구를 못 만듦 (서버 판정 값은 바꾸지 말라는 규칙, 코드 몸 관절 위치는 `ext_meas`·`rag_shot` 에 이미 '골반 높이 6cm 차' 정도만 있음). 다음 작업으로 남김.

## 8. 소프트웨어 렌더 한계

- 이 환경에는 GPU 가 없어 llvmpipe 로 그렸다 — 포즈·색·실루엣은 정확하지만 그림자·외곽선 굵기·톤매핑은 실제와 다르고 (그림이 어둡고 푸른 이유: 환경광을 낮게 둔 시트 전용 조명), 프레임 사이 움직임 (크로스페이드 0.1초, 클립 전환의 튐) 은 정지 그림 몇 장으로는 못 봄.
- GPU ms 는 측정 불가. 클립 추가로 CPU 는 `Ext.sync` 에 클립 샘플링이 늘지만 (닌자 기준 W30 측정 몸 하나 ~0.1ms) 3명 추가를 따로 재지는 않음.
- 1인칭 팔은 `move_shot.gd` 정지 장면 (판·카메라 없음) — 실제 판의 시야·FOV 와 다를 수 있음.
