재혁 (2026-11-08): "에니메이션/모델링 확인/검토/향상". 브랜치 `w/W33` (= `w/W31` 59e6347). 같은 시각 W32 가 그림자·world/·렌더 설정을 만지는 중 — **겹치지 말고 `chars/`·`tools/blender/`·`ext/` 에셋·모션 쪽만**.

## 현황
- 새 모델 4명 (`assets/models/ext/<id>.glb`): 모션은 **코드 구동 자세를 뼈에 옮기는 방식** (`figure_motion`·`moves` → `Ext.sync`). **닌자만** 손으로 만든 클립 15개 (`ext_clips.gd`·`ninja_anim.glb`, idle·walk·run·jump·fall·land·평타 1~4·공중 평타 2·대시·표창·공중 표창) + 목도리 verlet. 탱크·사냥꾼·갈고리는 클립 없음 → "인형 같음" (척추 분배·빗장·손목·발목 없음, W23 보고).
- 한계: 클립이 수치 키프레임이라 이음 동작·무게감·발 미끄러짐 (IK 없음). 1인칭 팔 모션은 코드 관절 베낌. 모델링 쪽: 판 LOD 팀 색 칸 경계가 삼각형 하나만큼 어긋남 (닌자·탱크 8~19%), 탱크 낮음 LOD 가는 장식 뭉개짐, 사냥꾼 1인칭 소총 안 보임, 갈고리 오른 주먹 찢어진 조각, 탱크 1인칭 방패 가림, 방패 뒷면 구멍 막은 판, 코트 안감 비침 등.

## 1단계: 확인·검토 (고치기 전에 증거부터)
각 캐릭터마다 contact sheet 를 만들어 **눈으로 평가**하고 `docs/model-review-2026-11.md` 에 정리해 커밋:
- 동작별 (idle·걷기 4위상·달리기·점프·낙하·착지·평타 전부·스킬·필살기·대시·맞음·KO 쓰러짐·도발·승리) 3/4 뷰 + 옆 뷰 시트 (`tools/move_shot.gd`·`clip_shot.gd`·`rag_shot.gd`·`vm_shots.gd` 활용, 소프트웨어 렌더라도 포즈는 보임).
- 항목별 점수 (1~5) 와 결함 목록: 갈라짐·뚫림·가시·발 미끄러짐·무기 손 맞음·망토/코트/목도리 움직임·비율 어긋남 (코드 몸과 팔 길이 차이로 판정 위치 vs 보이는 타격 위치)·팀 색 칸 경계·텍스처 이음·1인칭 팔 모양/크기/가림·초상·대기실 쉬는 자세.
- 모델링 검사 (자동): 열린 모서리 수, 뒤집힌 면, 겹치는 UV, 스킨 가중치 합 1·뼈 수/정점 4 제한, 마스크 면적/경계 어긋남, 삼각형·텍스처 크기 (`tools/blender/tripo/verify_glb.py` 가 있으면 확장).
- 결함을 **영향도 × 고치기 쉬움** 순으로 표로: 상위 5~8개를 2단계에서 고침.

## 2단계: 향상 (1단계 표의 상위부터, 현실적으로)
후보 (검토 결과가 우선, 아래는 예상):
1. **탱크·사냥꾼·갈고리 동작 클립** — 닌자 방식 (`tools/blender/tripo/anim_ninja.py`·`clips_ninja.py` 를 캐릭터 일반화: 관절 각 표 → Blender FK 키프레임 → `<id>_anim.glb`, `ext_clips.gd` 상태→클립 매핑) 으로 idle·walk·run·jump·fall·land·평타·스킬 중 확실히 나아지는 것만 (탱크 = 무겁고 느린 걸음·방패 자세·해머 휘두름, 사냥꾼 = 소총 겨누기·구르는 달리기, 갈고리 = 갈고리 던지기·끌어당김·코트 자락). 맞음·경직·낙사·일어남·도발·승리는 계속 코드+래그돌.
2. **발 미끄러짐/바닥 맞추기** (간단 발 IK 또는 걸음 속도에 클립 속도 맞춤 — `ext_clips.gd` 의 클립 속도 = 이동 속도 비례, 발 접지 시점 고정).
3. **팀 색 칸 경계** — 마스크를 꼭짓점 판정 대신 **텍스처로 굽거나** 셰이더가 UV2 마스크 텍스처를 읽게 (W31 이 LOD 마다 알베도를 굽는 도구 `relod.py` 가 있음 — 마스크 텍스처도 같이 굽고 셰이더 `g3.gd` mask 경로가 텍스처 마스크를 쓰게; 안 되면 보고).
4. 사냥꾼 1인칭 소총 보이게 (viewmodel 쪽 최소 변경, `vm: true` attach 로 소총 소품), 탱크 1인칭 방패 가림 줄이기 (위치·크기 `vm` 값), 갈고리 오른 주먹 찢어진 조각 정리, 닌자·탱크 낮음 LOD 장식 뭉개짐.
5. 코드 몸과의 길이 차이 때문에 서버 판정 (주먹·칼 끝) 위치와 보이는 타격 위치가 어긋나는 것: 정량 측정 (모델 손 뼈 위치 vs 서버 타격 중심) 하고 `height`·`offset`·팔 스케일 보정으로 줄일 수 있으면.
6. Mixamo 애니메이션이 필요하다고 판단되면 **요청 목록** (캐릭터별 받을 동작 이름) 을 문서에 정리 (자동으로 받을 수 없음 — 재혁이 받아 줘야 함).
