## 1. 팀 색 칸 경계 — 마스크 텍스처
- `relod.py` 가 알베도와 같은 새 UV 로 마스크 (1024², 한 채널) 도 굽고 (`--mask-soft`), 사냥꾼처럼 판 LOD 가 stage UV 를 쓰는 모델은 `maskbake.py`. 툰 셰이더 `skin_mask_tex`·`use_skin_mask` (uniform 분기, 새 셰이더 변형·재질 수 변화 없음, W30 prewarm 그대로). 닌자·탱크·갈고리 stage 는 원본 UV 에 맞는 꼭짓점 마스크라 예전 판정 유지.
- 어긋남 (`relod.py` 가 stage 마스크와 꼭짓점 판정 마스크를 텍셀로 비교, 알베도 칸 대비): 닌자 missing 1.3~1.6% / spill 1.2~1.5%, 탱크 1.1~1.5 / 0.8~1.1, 갈고리 0.2~0.3 / 0.1~0.2 → 마스크 텍스처는 stage 마스크를 그대로 굽기 때문에 알베도와 같은 칸 (남는 어긋남 = 가장자리 1~3 텍셀 부드러움). 경계 삼각형 비율 (W33 닌자 48~55%·탱크 32~54%·사냥꾼 16~36%·갈고리 5~15%) 은 의미가 없어짐 — 경계가 삼각형이 아니라 텍셀. 테스트: 칸 넓이 ≥ 5% (닌자 17%·탱크 5.8~6.5%·갈고리 12.7~13.9%·사냥꾼 8.4%), 경계 텍셀 ≤ 25%.
- `1_mask_*_before_after.jpg` (판 낮은 LOD 가까이).

- 안 본 것: 프레임 사이 움직임·발소리 (코드 걸음 위상에 묶여 있어 클립 박자 ×1.6 과 안 맞음 — 소리 쪽은 안 건드림). `2_foot_*.jpg`.

## 6. 갈고리 찢어진 조각·코트 안감
- 오른 주먹에서 허리로 가던 가는 줄 = ① 몸에서 떨어진 부스러기 덩어리 (stage 85+3+1 삼각형, 판 LOD 33·26·20…) ② 코트-주먹을 잇던 '이음' 삼각형 (stage 19·LOD 10~19). `tripo/hook_bridge.py` (자세 21개 늘어남 검사) + `tripo/drop_shards.mjs` 로 빼냄 → stage 18720 → 18611, LOD 5000·3999·2999 → 4944·3956·2967. `6_hook_slivers_before_after.jpg` (왼 둘 전, 오른 둘 후).
- 안감 비침: glb 재질은 양면인데 툰 셰이더는 뒷면을 안 그림. `cull_disabled` 로 같은 자세 비교 → 차이 0.1% 미만 (코트 가장자리 몇 점), 아래 붉은 조각은 원래 디자인 (코트 안감) → 바꾸지 않음 (셰이더 변형·prewarm 비용 > 이득). 남은 점: 주먹 옆에 먼지 같은 점 몇 개 (이음을 뺀 뒤 남은 1 삼각형 덩어리는 한 번 더 정리해 없앰).

## 7. 서버 판정 vs 보이는 타격 위치 (`tools/hit_reach.gd`, 표 `7_hit_reach.csv`)
서버 평타 (`game-combat.js` `basicHit`, C# `Game.Combat`): step 만큼 앞으로 나간 뒤 중심 거리 ≤ range (1.8) 이고 부채꼴 (반각 60°) 안. 상대 몸 반폭 0.3 → 서버가 치는 가장 먼 몸 앞면 = step + range − 0.3 (중심에서). 보이는 끝 = 타격 단계 자세 (strike u 0.5·1.0) 에서 스킨 적용한 정점의 몸 앞쪽 최대 거리.
| 캐릭터·동작 | 서버 최대 앞면 | 보이는 끝 | 차 |
| --- | --- | --- | --- |
| 탱크 주먹 | 1.90 | 1.45 | −0.45 |
| 탱크 어깨 박치기 / 방패 올려치기 / 내려치기(공중) | 2.30 / 1.80 / 1.50 | 0.89 / 0.86 / 0.86 | −1.41 / −0.94 / −0.64 |
| 닌자 찌르기 / 반대 / 앞차기 / 올려 차기 | 1.80 / 1.80 / 1.80 / 1.70 | 0.94 / 0.80 / 0.94 / 0.96 | −0.86 ~ −1.00 |
| 사냥꾼 베기 / 반대 / 찔러 넣기 / 내려 베기 | 1.80 / 1.80 / 1.90 / 1.50 | 0.93 / 0.36 / 0.99 / 0.54 | −0.87 ~ −1.44 |
| 갈고리 휘두르기 / 주먹 / 내려치기 / 탕 / 스핀 | 1.50 / 1.90 / 1.80 / 1.70 / 1.50 | 0.85 / 0.97 / 0.78 / 0.57 / 0.75 | −0.65 ~ −1.13 |
- 해석: 4명 모두 보이는 끝이 서버 앞면보다 0.5~1.4 m 짧음 — 팔 길이 차이 (캐릭터 간 편차 0.4~0.6 m) 가 아니라 **모든 캐릭터 공통으로 서버 사거리 (1.8) 가 모델 팔보다 김**. 서 있을 때 끝 0.4~0.7 m. 코드 몸 (팔 0.67×1.15) 도 마찬가지 (JS 시절 설계값). 탱크 주먹 (−0.45) 만 가깝고 어깨 박치기·사냥꾼 반대 베기·갈고리 탕은 가장 어긋남 (보이는 끝이 몸 가까이).
- 제안만 (적용 안 함, 서버 값 불변): ① 가장 어긋나는 동작에 모델 쪽 앞으로 내딛기 (strike 동안 `offset.x` 또는 `Ext` 몸 이동 +0.2~0.4 m) 로 보이는 끝을 서버 값 쪽으로 ② 사냥꾼 반대 베기·갈고리 탕은 팔 뻗음 (`MOVES` S 의 shFwd/elbow) 을 키움 ③ 팔 스케일은 올리지 않음 (1.0 m 키 모델에서 팔 +50% 는 비율이 깨짐). 먼저 플레이에서 '닿기 전에 맞는다' 는 느낌이 실제로 나는지 확인한 뒤 작게.
