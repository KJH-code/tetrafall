## 할 일
1. **뼈 이름 매칭**: `chars/external.gd` 의 `ALIASES` (Mixamo 이름 매칭) 에 이 규격 이름을 추가하거나 `ext/cannon.json` 의 `bones` 덮어쓰기 — **규격 전체에 통하게 ALIASES 에 넣는 쪽을 권장** (바드가 같은 이름). 위팔 = `Upperarm` (빗장 `Clavicle` 는 안 씀), 팔꿈치 = `Forearm`, 무릎 = `Calf`, 목 = `NeckTwist01` 또는 `Head`, 골반 = `Pelvis`. 트위스트·Share 뼈는 부모를 따라가게 (안 맞춘 뼈 = 부모 따라감 규칙). 이름 매칭 테스트 (합성 모델) 에 이 규격 추가. 공용 코드 변경이라 탱크·닌자·사냥꾼 테스트 안 깨지게.
2. 원본 손질 (뼈대 노드/메시 어긋남 → 세계 좌표로 굽기), 앞 방향·크기·좌우 (코드 대포수의 대포 드는 손·쏘는 방향과 맞는지 — 코드 `char-cannon.js`·`moves`·viewmodel 읽고 필요하면 W22 처럼 뒤집기).
