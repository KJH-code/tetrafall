# W27 — 새 모델(--ext 기본 켬) 두 가지 화면 버그: 대기실 T 포즈, 사람 카드 초상 안 맞음

재혁 피드백 (2026-11-06, v0.1.9 직접 해 봄: "좋음" + 아래 둘). 브랜치 `w/W27` (= 작업 브랜치 c08d081). 새 모델 = 탱크·닌자·사냥꾼·갈고리 (`ext/*.glb`, `--ext` 기본 켬).

## 버그 1 — 대기실 캐릭터 고르기 화면 큰 캐릭터가 **T 포즈**
대기실(방 안·판 전) 왼쪽 큰 3D 내 캐릭터 (`world/` 또는 `ui/` 의 char stage — `client/char-stage.js` 에 해당하는 고도 쪽, `ui/portrait.gd stage_light`·`STAGE_*` 참고) 가 새 외부 모델일 때 팔을 벌린 T 포즈로 서 있음 (예전 코드 몸은 쉬는 자세 + 천천히 돎·도발). 원인 후보: 그 화면은 `body.pose`/`Ext.sync` 를 안 부르고 (관절 노드 회전 = 0 이면 모델 쉬는 자세 = T/A 포즈 그대로), 코드 몸은 조각 위치가 이미 쉬는 자세라 티가 안 남. 대기실 무대에 서는 사람(방 안 다른 사람) 몸·초상·연습 방 허수아비는 괜찮은지도 같이 확인. 고치기: 대기실 큰 캐릭터·무대 캐릭터가 매 프레임 (또는 만들 때) 쉬는 자세 (`figure_pose` idle·걸음 0) 를 `body.pose` 로 넣어 외부 몸이 코드 쉬는 자세가 되게, 고르면 나오는 도발 한 번·천천히 돎이 새 모델에서도 되게. 닌자는 클립 층 (`ext_clips.gd`) 이 idle 클립을 틀 수도 있음.

## 버그 2 — 화면 아래 사람마다 **% 옆 캐릭터 프로필 초상 아이콘이 다 안 맞음**
판 중 아래 카드 (`updatePlayers` 에 해당하는 고도 쪽 HUD 의 초상 + 큰 %) 와 대기실 캐릭터 카드·결과 표 초상 (`ui/portrait.gd` — 3D 몸을 화면 밖 SubViewport 에 그려 캐시) 에서 초상이 캐릭터 얼굴/상반신 프레이밍이 안 맞거나 (잘림·너무 작음·머리 위 빈칸·다리 쪽만), 새 모델과 예전 몸이 섞이거나, 색이 틀림. "다 안 맞음" = 새 모델 네 명 모두 + 예전 몸 4명도 의심. 모델마다 키·비율·머리 높이가 달라 예전 고정 프레이밍 (카메라 높이·거리) 이 안 맞는 것이 유력. 고치기: 초상 카메라를 외부 모델 높이·머리 위치에서 자동 맞춤 (cfg `height`·머리 뼈 위치·`label_lift` 활용) 또는 모델별 `portrait` 값 (json), 캐시 키가 `--ext` 여부·모델 파일에 맞게 갱신되는지, 팀 색 칸 (`tint:"mask"`) 이 초상에도 플레이어 색으로 나오는지.
