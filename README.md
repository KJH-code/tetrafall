# Tetrafall (가칭)

3D 폴가이즈식 PC 웹 대전 게임 1단계 프로토타입.
6×6×12 격자 필드에 하늘에서 테트리미노가 떨어지고, 플레이어끼리 서로를 **압사·낙사**시켜 마지막 생존자가 이긴다.

1단계의 목적은 하나: **"이 규칙에서 압사가 실제로 일어나는가"** 검증.
합격선: 2인, 3분 판, 5판 플레이했을 때 압사 킬이 판당 1번 이상.

## 실행 (호스트 PC)

```bash
npm install   # 처음 한 번
npm start
```

서버가 뜨면 콘솔에 접속 주소가 찍힌다:

```
Tetrafall 호스트 서버 실행 중 (포트 3000, 틱 30Hz, 인원 2)
이 PC에서:        http://localhost:3000
다른 PC에서 (Wi-Fi): http://192.168.0.12:3000
```

- 호스트 PC도 브라우저로 `http://localhost:3000` 에 들어간다 (먼저 들어온 사람이 호스트).
- 다른 PC는 같은 네트워크에서 브라우저로 `http://<호스트IP>:3000` 에 들어간다.
- 2명이 모이면 호스트 화면에 **시작** 버튼이 생긴다. 판이 끝나면 같은 자리에 **재시작** 버튼.
- 방화벽이 3000 포트를 막으면 열어주거나 `PORT=8080 npm start` 처럼 포트를 바꾼다.
- 빌드 과정 없음. 서버·클라이언트 모두 순수 JS ES 모듈. three.js 는 `node_modules` 에서 그대로 서빙.

## 조작

| 상황 | 키 |
|---|---|
| 이동 / 점프 / 대시 | WASD / Space / Shift |
| 시점 | 마우스 (화면 클릭으로 Pointer Lock) |
| 밀치기 (근접 넉백) | 좌클릭 |
| 투사체 발사 (넉백 아이템 필요) | 우클릭 |
| 블록 조종 중: xy 이동 / 수직축 회전 / 하드드롭 | 방향키 / Q, E / Enter |

조종 중에는 카메라가 하늘 시점(직교 탑다운)으로 바뀐다. WASD 로 캐릭터는 계속 움직일 수 있지만 대시·밀치기·발사는 무시된다. 8초 안에 안 떨구면 자동 낙하.

## 규칙 요약

- 테트리미노(평면 7종)가 z=12 에서 0.5초에 1칸씩 내려온다. 착지 3초 전부터 착지 칸에 그림자.
- 블록 셀이 플레이어와 겹치는 순간 **압사**. 필드 밖으로 떨어지면 **낙사**.
- 6×6 한 층이 꽉 차면 그 층이 사라지고 위의 블록·플레이어·아이템이 한 칸 내려앉는다.
- 조종권 아이템(하늘색)을 먹으면 다음 블록을 조종. 넉백 아이템(빨강)을 먹으면 투사체 1발.
- 넉백을 맞으면 0.5초 경직. 경직 중엔 조작 불가, 추가 넉백 무시.

## 튜닝 상수

**`shared/config.js`** 한 파일. 낙하 속도, 조종 시간, 넉백 세기, 경직 시간, 이동 속도, 아이템 재스폰 시간, 인원 수 등 전부 여기.
바꾼 뒤 `npm start` 를 다시 하면 된다 (클라이언트는 새로고침).

## 디버그 로그 (합격선 측정)

서버 콘솔에 판마다 찍힌다:

```
===== ROUND 3 종료 | 길이 2:41 | 승자: P2 =====
  사망: P1 압사@2:41
  이번 판: 압사 1 / 낙사 0
  누적 3판: 압사 2 (판당 0.67) / 낙사 1
```

그 외 사망 순간(원인·시각·위치), 아이템 획득, 조종 시작/하드드롭, 밀치기·투사체 적중과 경직 무시, 층 클리어도 한 줄씩 찍힌다.

## 구조

```
server/index.js   정적 파일 + WebSocket + 30Hz 고정 틱 루프 (npm start 진입점)
server/game.js    게임 상태의 권위: 격자, 블록 낙하, 플레이어 AABB 물리, 넉백, 압사·낙사, 층 클리어, 로그
shared/config.js  튜닝 상수 전부
shared/pieces.js  테트리미노 모양·회전
client/main.js    WebSocket, 입력 전송, HUD, 렌더 루프
client/render.js  three.js 장면 (단색 블록, 1인칭 / 하늘 시점 카메라)
client/input.js   키보드·마우스 (Pointer Lock)
test/game.test.js 서버 규칙 단위 테스트 (npm test)
```

클라이언트는 입력만 보내고 서버 상태를 그대로 그린다 (예측 없음). LAN 전제.

## 작업 규약

브랜치에서 작업 → `main` 에는 fast-forward merge 로만 반영.
