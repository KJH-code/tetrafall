## 재료
`tools/blender/tripo/src/ninja_tripo_rigged.glb` — Tripo 자동 리깅 결과를 meshopt 풀어 놓은 것 (`decode_meshopt.mjs`). 스킨 메시 하나, 17,756 삼각형, 뼈 65개 (Mixamo 이름 `mixamorig:*`, 손가락 포함), 텍스처 3장(알베도 jpg·ORM jpg·노멀 png), 애니메이션 없음. 후드 + 마스크 + 붉은 목도리 + 등에 칼 두 자루, 7등신쯤 영웅 비율.
`pose_test.py` = Blender 에서 자세 시험 (쉬기·팔 들기·쪼그림·걷기) — 목도리가 큰 자세에서 허공으로 뻗음, 몸통·다리 스킨은 깔끔.

## 할 일
1. `godot/client/assets/models/ext/ninja.glb` + `ninja.json` 으로 `--ext` 에 넣기 (`chars/EXTERNAL.md`, `ALIASES` 로 Mixamo 이름 자동 매칭됨 — 안 되는 뼈 있으면 보고/보강). 크기(height)·yaw·offset·이름표 `label_lift`·1인칭 `vm_from`/`vm_snap`(손 아래만 스킨으로 자르면 깨짐 → W20 처럼 필요하면 닫힌 1인칭 팔 메시 `vm_node` 를 만들되, 이 모델은 팔이 일반 옷소매·장갑이라 팔꿈치 아래 스킨 삼각형 자르기가 될 수도 있으니 먼저 시험하고 깨지면 W20 방식).
2. 텍스처: 2048 이하 jpg/png, 파일 용량 줄이기 (meshopt 금지 — Godot 이 못 읽음, 이미 푼 파일). 판용 LOD (`lods`, W20 `lods.mjs`) 4~5천 / 대기실·초상 1.5만 / 1인칭. 스킨 메시라 LOD 도 스킨 유지 확인 (뼈 가중치·UV 이음선 안 찢어지게 meshopt 단순화).
3. **팀 색**: 붉은 목도리를 W20 탱크의 `tint:"mask"` 방식(밝기만 남긴 회백 + UV2 표시 → 플레이어 색 곱하기)으로. 대기실 무대에서 색 3종 확인.
4. 닌자 코드 스킬·모션과 맞는지: 닌자 대시·평타·필살기 자세(`figure_motion`·`moves`가 우리 관절을 돌림)에서 갈라짐·뚫림·목도리 뻗음 확인. 목도리가 큰 자세에서 허공으로 뻗어 어색하면 목도리 뼈를 정리하거나 가중치를 몸통 쪽으로 조정.
5. 무기(칼 등에 꽂힌 것은 모델에 포함). 손에 드는 단검/수리검 등 닌자 소품이 기존 코드에 있으면 손 관절에 그대로 붙게 두기 (`keep`/`attach` 규칙, EXTERNAL.md 8절).
6. 검증: `tests/run_tests.gd` 통과 유지(외부 테스트가 닌자 뼈를 본다면 맞춤), `tools/shader_check.gd`(xvfb gl_compatibility), `--ext` 실제 화면 캡처 — 대기실 큰 캐릭터·초상·판 3인칭 걷기/대시/평타/필살기·1인칭 팔(평타 5프레임)·팀 색 3종. 캡처 경로를 보고에 (커밋 안 함).
